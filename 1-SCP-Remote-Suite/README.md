# SCP-Remote Suite — ชุดดูแลคอมพิวเตอร์โรงพยาบาล

ชุดเครื่องมือของทีมไอที **โรงพยาบาลสีชมพู** สำหรับดูแลคอมพิวเตอร์ทั้งโรงพยาบาล เผยแพร่เพื่อการศึกษาและนำไปปรับใช้

| โฟลเดอร์ | คืออะไร |
|---|---|
| `server/` | **SCP-Remote** เว็บดูแลเครื่องทั้ง รพ. รีโมตเข้าเครื่อง ตรวจสุขภาพเครื่อง สุขภาพดิสก์ ใบงานช่างพร้อมวิธีซ่อม ผัง รพ. 2.5 มิติ หน้ามือถือ ตรวจเช้าอัตโนมัติ (ต่อยอดจาก MeshCentral) |
| `tools/SCPclear-plus/` | **SCPclear** โปรแกรมทำความสะอาดและปรับแต่งเครื่องที่หน้าเครื่อง (PowerShell) พร้อมชุดฟอนต์ไทย |
| `tools/SCPPrint/` | **SCPPrint** แชร์เครื่องพิมพ์ผ่านพอร์ต 9100 ให้เครื่องอื่นในวงแลนพิมพ์ผ่านได้ (Python) มีตัวติดตั้งสำเร็จรูปใน `bin/` |

## ติดตั้งครั้งเดียวจบ

1. ดาวน์โหลดทั้งโฟลเดอร์ (ปุ่ม **Code → Download ZIP** บน GitHub) แล้วแตกไฟล์
2. ดับเบิลคลิก **`START-HERE.cmd`** แล้วกด Yes เมื่อ Windows ขอสิทธิ์ผู้ดูแล
3. ตัวติดตั้งจะทำให้เองทั้งหมด:
   - ตรวจ Node.js 20 ขึ้นไป ถ้ายังไม่มีจะถามว่าจะติดตั้งด้วย winget ไหม
   - ติดตั้งแพ็กเกจ และสร้างหน้าเว็บภาษาไทย
   - สร้างทางลัดบนเดสก์ท็อป: **SCP-Remote**, **SCPclear**, **ติดตั้ง SCPPrint**
   - ถามว่าจะให้ SCP-Remote เปิดเองทุกครั้งที่เปิดเครื่องไหม (ติดตั้งเป็นบริการ Windows)
   - เปิดเบราว์เซอร์ไปที่ https://127.0.0.1:8443
4. สร้างบัญชีแรก บัญชีนี้จะเป็นผู้ดูแลระบบ (เบราว์เซอร์จะเตือนเรื่องใบรับรอง เป็นปกติ กด Advanced → Continue)

จากนั้นดาวน์โหลดตัวติดตั้งเอเจนต์จากหน้าเว็บ ("เพิ่มเอเจนต์") ไปลงที่เครื่องลูก เครื่องลูกจะขึ้นบนแดชบอร์ด

## ติดตั้งเองทีละขั้น (ถ้าไม่ใช้ START-HERE)

```powershell
cd server
npm ci
npm run build:hospital
npm run start:hospital          # เปิดชั่วคราว
npm run service:install         # หรือติดตั้งเป็นบริการ Windows (PowerShell แบบผู้ดูแล)
```

**คู่มือฉบับสมบูรณ์** (ติดตั้ง ใช้งาน กระบวนการ เอเจนต์ พัฒนาต่อ แนวทางต่อไป): `คู่มือ-SCP-Remote-ฉบับสมบูรณ์.html` หรือ `.pdf`

คู่มือรายฟีเจอร์ภาษาไทยอยู่ที่ `server/hospital/*.md` เริ่มที่ `server/hospital/README.md` และ `server/README-TH.md`

## สิ่งที่ไม่ได้รวมมา (ตั้งใจ)

- ข้อมูลจริงของโรงพยาบาล: ฐานข้อมูล การตั้งค่า ใบรับรอง กุญแจ รายชื่อเครื่องและผู้ใช้ ระบบจะสร้างของใหม่ให้ตอนเปิดครั้งแรก
- ชุดลง Windows จากระยะไกล

## ก่อนใช้จริง

- เปลี่ยนชื่อ โลโก้ และวงเครือข่ายที่อนุญาต (`node scripts/allow-subnet.js add 192.168.x.0/24` ในโฟลเดอร์ `server`) ให้เป็นของหน่วยงานตัวเอง คู่มือมี IP ภายในของ รพ.สีชมพูเป็นตัวอย่าง
- ใช้กับเครื่องที่หน่วยงานมีสิทธิ์ดูแลเท่านั้น และแจ้งผู้ใช้ตามนโยบายของหน่วยงาน
- อย่าเปิดพอร์ต 8443 ออกอินเทอร์เน็ตตรง ๆ ถ้าต้องใช้จากข้างนอก ดู `server/hospital/REMOTE-OVER-INTERNET.md`
- เปิดยืนยันตัวตน 2 ชั้นให้บัญชีผู้ดูแล

## สัญญาอนุญาต

- `server/` ต่อยอดจาก [MeshCentral](https://github.com/Ylianst/MeshCentral) สัญญาอนุญาต Apache-2.0 (`server/LICENSE`) ส่วนที่ รพ.สีชมพูเพิ่มเผยแพร่ภายใต้สัญญาเดียวกัน
- ฟอนต์: ฟอนต์แห่งชาติ (SIPA) ใช้ได้ฟรี และ Google Fonts สัญญาอนุญาต OFL (`server/public/fonts/thai/licenses/`, `tools/SCPclear-plus/Fonts/OFL.txt`)
- SCPclear และ SCPPrint พัฒนาโดยทีมไอที โรงพยาบาลสีชมพู
