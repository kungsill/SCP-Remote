# SCP-Remote — ระบบดูแลคอมพิวเตอร์โรงพยาบาล (ฉบับเผยแพร่เพื่อการศึกษา)

ระบบรีโมตและดูแลคอมพิวเตอร์ทั้งโรงพยาบาลจากหน้าจอเดียว พัฒนาโดยทีมไอที โรงพยาบาลสีชมพู
ต่อยอดจาก [MeshCentral](https://github.com/Ylianst/MeshCentral) 1.2.5 (สัญญาอนุญาต Apache-2.0 ดูไฟล์ `LICENSE`)

## มีอะไรบ้าง

| ส่วน | ไฟล์หลัก |
|---|---|
| หน้าเว็บภาษาไทย ธีม รพ. แดชบอร์ด | `public/scripts/scp-dashboard.js`, `public/styles/scp-*.css`, `views/default.handlebars` |
| ผัง รพ. 2.5 มิติ | `public/scripts/scp-map.js`, `scp-map-anime.js` |
| ตรวจสุขภาพเครื่อง + ปุ่มแก้ + สุขภาพดิสก์ + ใบงานช่าง + วิธีซ่อม | `public/scripts/scp-health.js` · คู่มือ `hospital/HEALTH-CHECK.md` |
| ตรวจเช้าอัตโนมัติ 07:30 | `hospital/morning-check.js` |
| หน้ามือถือ /m | `hospital/mobile.js`, `public/scripts/scp-mobile.js` |
| งานไอที แจ้งซ่อม คลังไดรเวอร์ | `hospital/operations.js` · คู่มือ `hospital/IT-OPERATIONS.md` |
| ตัวติดตั้งเอเจนต์สำหรับเครื่องลูก | `hospital/client-setup/` |
| ชุดทดสอบ | `hospital/tests/` (รัน `npm run test:hospital`) |
| คู่มือทั้งหมด (ภาษาไทย) | `hospital/*.md` เริ่มที่ `hospital/README.md` |

## ลองรันบนเครื่องตัวเอง

ต้องมี Node.js 20 ขึ้นไป (ทดสอบกับ 22.17) แล้วเปิด PowerShell ในโฟลเดอร์นี้:

```powershell
npm ci
npm run build:hospital
npm run start:hospital
```

เปิด https://127.0.0.1:8443 บัญชีแรกที่สร้างจะเป็นผู้ดูแลระบบ
ใบรับรองที่สร้างให้อัตโนมัติเป็นแบบทดสอบ เบราว์เซอร์จะเตือน กด "ดำเนินการต่อ" ได้

## สิ่งที่ไม่ได้รวมมา (ตั้งใจ)

- ฐานข้อมูล การตั้งค่า ใบรับรอง และกุญแจของเซิร์ฟเวอร์จริง (`.local/`): ระบบสร้างใหม่ให้ตอนรันครั้งแรก
- รายชื่อเครื่อง ผู้ใช้ และผลตรวจของโรงพยาบาล
- `node_modules`: ติดตั้งใหม่ด้วย `npm ci`
- โน้ตงานภายในของทีม

ในคู่มือมีที่อยู่ IP ภายในของโรงพยาบาลเป็นตัวอย่าง ให้เปลี่ยนเป็นของหน่วยงานตัวเอง

## ก่อนนำไปใช้จริง

- เปลี่ยนชื่อ โลโก้ และวงเครือข่ายที่อนุญาตให้เป็นของหน่วยงานตัวเอง (`node scripts/allow-subnet.js add ...`)
- ใช้กับเครื่องที่หน่วยงานมีสิทธิ์ดูแลเท่านั้น และแจ้งผู้ใช้เครื่องตามนโยบายของหน่วยงาน
- ฟอนต์ใน `public/fonts/thai/` เป็นฟอนต์ใช้ฟรี (ฟอนต์แห่งชาติ SIPA และ Google Fonts สัญญาอนุญาต OFL อยู่ใน `licenses/`)
