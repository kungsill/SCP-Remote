# ถอนแอนตี้ไวรัสเก่าที่ถอนไม่ออก (เช่น ESET NOD32 32 บิต)

เอกสารนี้เป็นขั้นตอนสำหรับช่าง ใช้เมื่อเครื่องมีแอนตี้ไวรัสรุ่นเก่าค้างอยู่ ถอนไม่ได้ และฐานข้อมูลไวรัสไม่อัปเดตมานาน ทุกวิธีในนี้เป็นวิธีที่**ผู้ผลิตรองรับ** ไม่มีวิธีหยุดเซอร์วิสหรือปิดไดรเวอร์ป้องกันตัวเองด้วยมือ เพราะถอนไม่หมดแล้วเครื่องจะแย่กว่าเดิม

ที่มา: คู่มือทางการของ ESET [KB2289](https://support.eset.com/en/kb2289) บวกกระทู้และบทความที่ค้นเจอ (ระบุไว้ท้ายเอกสาร) ส่วนที่ผมเขียนจากความรู้ทั่วไปและยังไม่ได้ตรวจกับแหล่งตรง ๆ จะมีป้าย **(ตรวจก่อนใช้)**

## ก่อนเริ่ม: ต้องถอนจริงหรือเปล่า

1. ดูว่าเครื่องมีแอนตี้ไวรัสอะไรอยู่: Windows Security → Virus & threat protection → ดูหัวข้อ "Who's protecting you" หรือรายการโปรแกรมใน Settings → Apps
2. **ถ้าแอนตี้ไวรัสตัวนั้นเปิดอยู่และอัปเดตล่าสุด อย่าเพิ่งถอน** เพราะมันคือตัวที่ป้องกันเครื่องอยู่ ถอนเมื่อมีตัวแทนพร้อมแล้วเท่านั้น
3. เมื่อไม่มีแอนตี้ไวรัสตัวอื่นลงทะเบียนอยู่ Microsoft Defender จะกลับมาทำงานเอง ถ้ามีตัวเก่าค้างอยู่ Defender จะอยู่โหมด passive และไม่อัปเดตฐานข้อมูลให้ ซึ่งเป็นสาเหตุที่พบบ่อยของเครื่องที่ไม่มีการอัปเดตไวรัสเลย **(ตรวจก่อนใช้)**
4. สำรองข้อมูลสำคัญ และจดว่าเครื่องนั้นมีรหัสผ่านป้องกันการตั้งค่า ESET หรือไม่ (ดูหัวข้อรหัสผ่านด้านล่าง)

## ลำดับวิธีถอน ทำทีละขั้นจนกว่าจะหาย

### ขั้น 1 ถอนด้วยตัวถอนของมันเอง

- Settings → Apps → Installed apps → เลือกโปรแกรม → Uninstall แล้วรีสตาร์ท
- ถอนแบบเงียบด้วยบรรทัดคำสั่ง (เปิด CMD แบบ Administrator): `msiexec /x {รหัส GUID ของโปรแกรม} /qn /norestart` หา GUID ได้จากรีจิสทรี `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall` (โปรแกรม 32 บิตบน Windows 64 บิตอยู่ใต้ `Wow6432Node`) ดูที่ค่า `DisplayName` และ `UninstallString` GUID เป็นชื่อคีย์ในรูป `{xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}` **รหัสของแต่ละรุ่นไม่เหมือนกัน ต้องดูจากเครื่องนั้น**
- รหัสผลลัพธ์ของ `msiexec` ที่ควรรู้ (รหัสมาตรฐานของ Windows Installer): `0` สำเร็จ · `3010` สำเร็จ ต้องรีสตาร์ท · `1641` สำเร็จ และกำลังรีสตาร์ท · `1618` มีการติดตั้งอื่นทำอยู่ รอแล้วลองใหม่ · `1605` ไม่พบโปรแกรมนี้ · `1603` ผิดพลาดร้ายแรง ในกรณีของ ESET ที่ตั้งรหัสผ่านไว้ รหัสนี้อาจเกิดเพราะรหัสไม่ตรง ดูหัวข้อถัดไป **(ตรวจก่อนใช้)**

### รหัสผ่านป้องกันการถอน (ESET)

- ESET มีรหัสผ่านป้องกันการตั้งค่า ตั้งใจให้มัลแวร์ถอนตัวมันเองแบบเงียบไม่ได้ ผู้ดูแลของ ESET อธิบายไว้ในกระทู้ [Wilder's Security](https://www.wilderssecurity.com/threads/silent-uninstall-w-password.331697/)
- ถ้าเป็นเครื่องที่ รพ. ตั้งรหัสไว้เอง ให้ใช้รหัสนั้น ถ้ามีกระทู้เก่าระบุว่าใช้พารามิเตอร์ `PASSWORD=` กับ `msiexec` ได้ (รุ่น NOD32 v4) แต่บางคนรายงานว่ารหัสถูกปฏิเสธด้วยรหัส 1603 จึงไม่แน่ใจว่าใช้ได้กับรุ่นของคุณ ([กระทู้](https://www.wilderssecurity.com/posts/1496292))
- ถ้าเครื่องถูกคุมจากคอนโซลของ ESET (ERA / ESET PROTECT) ให้ถอนจากคอนโซลหรือปลดการป้องกันในนโยบายก่อน
- ถ้าลืมรหัส ให้ติดต่อฝ่ายสนับสนุนของ ESET เป็นทางที่ผู้ผลิตรองรับ

### ขั้น 2 เครื่องมือถอนทางการของผู้ผลิต

สำหรับ ESET ใช้ **ESET Uninstaller** ตามคู่มือ [KB2289](https://support.eset.com/en/kb2289):

1. ดาวน์โหลด ESET Uninstaller จากหน้าคู่มือของ ESET เอง (อย่าโหลดจากเว็บอื่น) แล้วคัดลอกใส่แฟลชไดรฟ์หรือวางบนเครื่อง
2. **รีสตาร์ทเข้า Safe Mode** (ดูวิธีด้านล่าง)
3. รันไฟล์ในนั้นแบบ Administrator แล้วทำตามหน้าจอ เลือกผลิตภัณฑ์ที่จะถอน
4. รีสตาร์ทกลับเข้า Windows ปกติ

สวิตช์ที่คู่มือกล่าวถึง (รันด้วย `ESETUninstaller.exe /help` เพื่อดูทั้งหมด):

| สวิตช์ | ความหมาย |
| --- | --- |
| `/force` | ลบผลิตภัณฑ์และส่วนประกอบของ ESET ที่พบทั้งหมดโดยไม่ถามซ้ำ |
| `/reinst` | เครื่องมือจะแจ้งเมื่อต้องใช้ ตอนใช้ **ค่าการ์ดเครือข่ายจะถูกรีเซ็ต** ควรเก็บค่าก่อนด้วย `netsh -c interface dump > netcfg.txt` แล้วเรียกคืนด้วย `netsh -f netcfg.txt` |
| `/mode=offline` / `/mode=online` | offline สำหรับสื่อบูตแบบ CD/USB, online สำหรับฮาร์ดดิสก์ ปกติเครื่องมือเลือกให้เอง ใช้เมื่อมันตรวจไม่พบเท่านั้น |

คู่มือแนะนำให้ส่งออกการตั้งค่า ESET ก่อน เพราะไม่ถูกเรียกคืนให้เองเมื่อติดตั้งใหม่

ยี่ห้ออื่น ทางการของผู้ผลิตแต่ละเจ้ามีเครื่องมือถอนของตัวเอง เช่น Kaspersky (kavremover), McAfee (MCPR), Norton (Norton Remove and Reinstall), Avast และ AVG (Avast Clear / AVG Clear) ชื่อและที่ดาวน์โหลดเปลี่ยนบ่อย **(ตรวจก่อนใช้)** ค้นจากเว็บของผู้ผลิตโดยตรง

### วิธีเข้า Safe Mode

- Windows 10/11: กด Shift ค้างแล้วเลือก Restart → Troubleshoot → Advanced options → Startup Settings → Restart → กด 4 (Safe Mode)
- หรือ `msconfig` → แท็บ Boot → ติ๊ก Safe boot → Minimal → OK → รีสตาร์ท **อย่าลืมติ๊กออกหลังเสร็จ** ไม่งั้นเครื่องจะเปิดเข้า Safe Mode ทุกครั้ง
- **เครื่องจะต่อ SCP-Remote ไม่ได้ขณะอยู่ใน Safe Mode** เอเจนต์ไม่ทำงานที่นั่น ต้องมีคนอยู่หน้าเครื่อง อย่าสั่งเข้า Safe Mode จากระยะไกลกับเครื่องที่ไม่มีคนเฝ้า

### ขั้น 3 ถ้ายังไม่ออก

- รีสตาร์ทแล้วลองขั้น 2 ซ้ำ
- ตรวจว่าพื้นที่ดิสก์ยังเหลือพอ และ Windows Installer ไม่ค้าง (บริการ Windows Installer ต้องไม่ถูกปิด)
- รัน `sfc /scannow` และ `DISM /Online /Cleanup-Image /RestoreHealth` ถ้าเครื่องมี Windows Installer เสียหาย ถอนอะไรก็ไม่ผ่าน
- ติดต่อฝ่ายสนับสนุนของผู้ผลิต และเก็บไฟล์บันทึกของเครื่องมือถอนไว้ส่งให้

## หลังถอนเสร็จ ตรวจให้ครบ

1. Windows Security แสดงว่า Microsoft Defender เปิดอยู่ (ไม่ใช่ passive) และกด "Check for updates" ที่ Virus & threat protection updates ให้ฐานข้อมูลอัปเดต
2. เครื่องไม่มีแอนตี้ไวรัสสองตัวทำงานซ้อนกัน
3. ถ้ามี ESET ตัวใหม่รุ่นที่ใช้ได้แล้วค่อยติดตั้ง ให้ลงหลังถอนตัวเก่าหมด และรีสตาร์ทแล้ว
4. ดูใน SCP-Remote: ตรวจสุขภาพเครื่องนั้นอีกครั้ง (🩺) แล้วดูว่า "ฐานข้อมูลไวรัส" เป็นปัจจุบัน

## ใช้ใน SCP-Remote

**หน้ารวม:** 🛠️ เครื่องมือช่าง SCPclear → แท็บ **🛡️ แอนตี้ไวรัส** → "ตรวจแอนตี้ไวรัสทุกเครื่องที่ออนไลน์" (อ่านอย่างเดียว) เรียงเครื่องที่ไม่มีตัวป้องกันที่ใช้งานได้ขึ้นก่อน พร้อมชื่อ/รุ่นของตัวเก่าที่ค้างและสถานะ Defender (Passive = ถูกตัวเก่าบังอยู่)

**ทีละเครื่อง:** หน้าต่างรายละเอียดเครื่อง → ส่วน 🧰 เครื่องมือช่าง → **🛡️ แอนตี้ไวรัส: ตรวจ / ถอน** จะขึ้นตารางโปรแกรมแอนตี้ไวรัสที่ลงอยู่ เลือกตัวที่ต้องการแล้วกด **🗑️ ถอนด้วยตัวถอนของมัน** (ถามยืนยันก่อน)

สิ่งที่ปุ่มถอนทำ: เรียกตัวถอนแบบเงียบของโปรแกรมเอง (`msiexec /x {GUID} /qn /norestart`) จนจบหรือครบ 20 นาที แล้วตรวจว่ารายการหายไปจริงไหม รายงานรหัสผลลัพธ์ ต้องรีสตาร์ทไหม และสถานะ Defender หลังถอน

สิ่งที่ปุ่มถอน **ไม่ทำ** (ตั้งใจ):
- ไม่ถอนตัวที่เปิดอยู่และฐานไวรัสล่าสุด (เป็นตัวป้องกันเครื่องอยู่) และไม่ถอนเอเจนต์รีโมต
- ไม่หยุดเซอร์วิส ปิดไดรเวอร์ ลบไฟล์หรือรีจิสทรีของมัน เพื่อฝ่าการป้องกันตัวเอง เทสต์ใน `hospital/tests/tech.test.js` ตรวจว่าสคริปต์ไม่มีคำสั่งแบบนั้น
- โปรแกรมที่ไม่มีตัวถอนแบบเงียบ จะขึ้นว่าต้องถอนที่หน้าเครื่อง
- ถ้าถอนไม่หาย (ติดรหัสผ่าน หรือป้องกันตัวเอง) ระบบบอกว่า "ยังติดตั้งอยู่" ให้ใช้ขั้น 2 ในคู่มือนี้ที่หน้าเครื่อง

ปุ่ม **ถอดออก** ในหน้ารายการโปรแกรมเดิม (`scp-programs.js`) ยังใช้ได้กับโปรแกรมทั่วไป และมีกฎไม่ถอนแอนตี้ไวรัสที่กำลังป้องกันเครื่องอยู่เช่นกัน
