# ศูนย์ติดตามงาน IT

เปิดจากศูนย์งาน IT โรงพยาบาล → **ศูนย์ติดตามงาน** หลังอัปเดตหน้าเว็บด้วย Ctrl+Shift+R

งานต่อยอดรอบนี้อิงรายการฟังก์ชันที่ผู้ใช้ส่งไว้ เพราะไม่มีชื่อรายการหมายเลข 4–8 เดิมอยู่ในประวัติที่เข้าถึงได้:

1. **แจ้งเตือนในเว็บ**: รวมข้อค้นพบของแดชบอร์ดและเครื่องเฝ้าระวังที่ออฟไลน์ ไม่ส่งข้อความออกไปภายนอก ไม่ใช่ประวัติการเกิดเหตุย้อนหลัง
2. **สถานะงาน**: แสดงผลล่าสุดของงานไดรเวอร์และล้างไฟล์จากเอเจนต์ หากยังรายงานความคืบหน้าแต่ไม่มีข้อมูลใหม่เกิน 15 นาที จะแสดงว่ายังไม่ทราบผล ไม่สรุปว่าสำเร็จ ไม่ใช่คิวสั่งงานใหม่และไม่รวมงานทุกประเภท
3. **ประวัติซ่อม**: ค้นเครื่อง ห้อง หัวข้อ และบันทึกการซ่อม เปิด/แก้ใบงานผ่านแท็บแจ้งซ่อมเดิม
4. **รายงาน / CSV**: รายการเครื่องที่มีสิทธิ์เห็น ส่งออกได้ตามตัวกรอง ใช้ UTF-8 BOM และป้องกันค่าเริ่มต้นที่อาจถูกโปรแกรมตารางคำนวณตีความเป็นสูตร
5. **สุขภาพสำรอง**: เฉพาะผู้ดูแลสูงสุด ตรวจอายุไฟล์ล่าสุด SHA-256 ของสำเนา และผลกู้คืนที่ต้องตรงกับชื่อไฟล์ล่าสุด ทั้งการแตกไฟล์และเปิดเซิร์ฟเวอร์ทดสอบต้องผ่าน ใช้เครื่องมือทดสอบกู้คืนเดิมจากแท็บสำรองข้อมูล

แต่ละหน้าจะดึงข้อมูลใหม่ทุก 15 วินาทีขณะเปิด ปิดแล้วหยุดดึงข้อมูล รักษาข้อความค้นหาไว้ เมื่อโหลดไม่สำเร็จแสดงข้อผิดพลาดและไม่ให้ส่งออกข้อมูลเก่าเป็นรายงานใหม่

แก้ข้อผิดพลาดเดิม: `snapshot()` สำหรับรายงานชนกับฟังก์ชันถ่ายภาพ thumbnail ในแดชบอร์ด เปลี่ยนชื่อส่วนถ่ายภาพเป็น `captureThumbnail()` และเพิ่มการทดสอบว่าอ่านสรุปเครื่องได้โดยไม่เปิดเซสชันรีโมต

ยังไม่ถือว่าผ่านการรับงานภาคสนามทั้งหมด: การรีโมตจริง ปุ่มหยุดเครื่องลูก คลิปบอร์ดไฟล์สองทิศทาง และคำเตือนก่อนรีสตาร์ต ต้องทดสอบกับเจ้าหน้าที่หน้าเครื่องตามรายการเดิม งานรอบนี้ไม่สั่งรีสตาร์ต ลบไฟล์ หรือติดตั้งซอฟต์แวร์บนเครื่องใช้งาน
