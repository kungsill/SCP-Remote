# ล้างไฟล์ชั่วคราว

เปิดแดชบอร์ดแล้วกด **ล้างไฟล์ชั่วคราว** ที่เครื่อง Windows ออนไลน์ ตรวจชื่อเครื่องและยืนยันหนึ่งครั้ง ระบบทำงานเบื้องหลังโดยไม่ปิดโปรแกรมหรือรีสตาร์ต

ลบเฉพาะไฟล์ที่ทั้งวันสร้างและวันแก้ไขเก่ากว่า 7 วัน ใน Windows Temp และ AppData\Local\Temp ของโปรไฟล์ผู้ใช้ปกติ ข้าม reparse points/junctions และไฟล์ที่ลบไม่ได้ ไม่ลบโฟลเดอร์ ไม่แตะ Downloads เอกสาร Desktop ประวัติเบราว์เซอร์ รหัสผ่าน ถังขยะ หรือ Windows Update cache

แสดงจำนวนและขนาดไฟล์ที่ลบ รวมทั้งพื้นที่ว่างของไดรฟ์ระบบก่อน–หลัง ขนาดไฟล์ที่ลบอาจต่างจากพื้นที่ว่างที่เพิ่ม เนื่องจากการบีบอัด ฮาร์ดลิงก์ และโปรแกรมอื่นที่ใช้งานดิสก์พร้อมกัน ไม่รับประกันว่าเครื่องจะเร็วขึ้น

ใช้สิทธิ์ Run Commands เดิมของ MeshCentral และมีบันทึกผู้สั่งในเหตุการณ์เครื่อง จำกัดหนึ่งงานต่อเครื่องด้วย mutex สูงสุด 120 วินาทีหรือ 100,000 รายการ หากถึงขีดจำกัดจะแสดงผลว่าทำได้บางส่วน หากไม่รับผลภายใน 180 วินาทีจะแสดงว่ายังยืนยันไม่ได้ ไม่รายงานว่าสำเร็จหรือเริ่มซ้ำอัตโนมัติ

ผลบนแดชบอร์ดอยู่เฉพาะหน้าเว็บที่เปิดอยู่ ไม่เก็บประวัติผลล้างในระบบงานซ่อมอัตโนมัติ โค้ดอยู่ที่ `public/scripts/scp-cleanup.ps1` และ `scp-cleanup.js` ทดสอบการลบจริงเฉพาะไฟล์จำลองที่สร้างขึ้นสำหรับทดสอบ ไม่ได้ล้างเครื่องลูกระหว่างพัฒนาฟังก์ชัน
