# ชุดติดตั้งสำหรับเครื่องลูก

สำหรับฝ่ายไอที ใช้ติดตั้ง SCP-Remote บนเครื่องผู้ใช้ โดยมีหน้าจอขอความยินยอมและช่องกรอกรหัสเครื่อง

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
| --- | --- |
| **`SCP-Remote-Setup.exe`** | **ไฟล์เดียวจบ** ตัวช่วยติดตั้งแบบกดถัดไปทีละหน้า ขอสิทธิ์ผู้ดูแลเครื่องเอง โลโก้ ไอคอน และไฟล์เอเจนต์ของกลุ่มอุปกรณ์ ฝังอยู่ในไฟล์นี้แล้ว |
| `Check-Network.cmd` | กดเมื่อติดตั้งแล้วเครื่องไม่ขึ้นในระบบ บอกว่าเครื่องอยู่วงไหนและวิ่งถึงเซิร์ฟเวอร์หรือไม่ ไม่ต้องใช้สิทธิ์ผู้ดูแล และไม่แก้อะไรบนเครื่อง |
| `Check-Network.ps1` | ตัวตรวจที่ไฟล์ด้านบนเรียกใช้ ถ้าเซิร์ฟเวอร์ย้ายที่อยู่ ให้แก้บรรทัด `$serverAddress` ในไฟล์นี้ |
| `agents/` | ไฟล์เอเจนต์ที่จะถูกฝังลงตัวติดตั้งตอนสร้าง **ไม่ต้องแจกไปเครื่องลูก** |
| `src/` | ไฟล์ต้นฉบับของตัวติดตั้ง **ไม่ต้องแจกไปเครื่องลูก** |

**ยังขาดไฟล์ตัวติดตั้งเอเจนต์** ซึ่งไม่ได้แถมมาในชุดนี้ เพราะไฟล์นั้นสร้างจากกลุ่มอุปกรณ์บนเซิร์ฟเวอร์ของแต่ละที่ ดาวน์โหลดครั้งเดียวแล้วใช้ได้ตลอด

## แนวคิด ทำชุดเดียวใช้ได้ทุกเครื่อง

ไม่ต้องเตรียมชุดติดตั้งแยกตามหน่วยงาน ให้ทำ **ชุดเดียว** แล้วใช้กับทุกเครื่อง

สร้างกลุ่มอุปกรณ์ไว้กลุ่มเดียวชื่อ **เครื่องใหม่** ใช้เป็นที่พักของเครื่องที่เพิ่งติดตั้ง เครื่องลูกทุกเครื่องใช้ไฟล์ติดตั้งตัวเดียวกัน พอติดตั้งเสร็จเครื่องจะเข้ามาอยู่ในกลุ่มนี้เอง พร้อม IP ชื่อเครื่อง ระบบปฏิบัติการ และรหัสเครื่องที่กรอกไว้ ผู้ดูแลระบบค่อยเลือกเครื่องแล้วสั่ง **ย้ายไปกลุ่มอุปกรณ์** ไปยังกลุ่มจริงทีหลัง เลือกทีละหลายเครื่องพร้อมกันได้

เครื่องลูกจึงมีงานเดียวคือกดติดตั้ง ไม่ต้องรู้ว่าตัวเองอยู่หน่วยงานไหน และฝ่ายไอทีไม่ต้องรู้ IP ของเครื่องลูกล่วงหน้า เพราะเอเจนต์เป็นฝ่ายวิ่งเข้ามาหาเซิร์ฟเวอร์เอง

ข้อจำกัดเดียวคือกลุ่มต้นทางและปลายทางต้องเป็นชนิดเดียวกัน ถ้าสร้างทุกกลุ่มเป็น **จัดการด้วยเอเจนต์ซอฟต์แวร์** เหมือนกันหมด ก็ย้ายข้ามกลุ่มได้อิสระ

## เตรียมชุดติดตั้ง ทำครั้งเดียว

1. เข้า `https://192.168.2.25:8443` ด้วยบัญชีผู้ดูแลระบบ
2. สร้างกลุ่มอุปกรณ์ชื่อ **เครื่องใหม่** ประเภท **จัดการด้วยเอเจนต์ซอฟต์แวร์**
3. เปิดกลุ่มนั้น ไปที่ **เพิ่มอุปกรณ์** แล้วดาวน์โหลดไฟล์เอเจนต์ **ทุกแบบที่โรงพยาบาลมีใช้**
   - **บริการ Windows 64 บิต** สำหรับเครื่องส่วนใหญ่
   - **บริการ Windows 32 บิต** สำหรับเครื่องเก่า
   - **บริการ Windows ARM 64 บิต** ถ้ามีเครื่องชิป ARM
4. วางไฟล์ที่ดาวน์โหลดมาทั้งหมดไว้ในโฟลเดอร์ `agents/` แล้วสั่ง

   ```powershell
   npm run build:setup-exe
   ```

5. ได้ `SCP-Remote-Setup.exe` ที่มีทุกอย่างอยู่ในไฟล์เดียว **ก๊อปไฟล์นี้ไฟล์เดียวไปเครื่องลูกได้เลย**

ไฟล์เอเจนต์ถูกคอมไพล์เข้าไปในตัวติดตั้ง ตอนใช้งานจะแตกไฟล์ที่ตรงกับสถาปัตยกรรมของเครื่องนั้นออกมาใช้เอง

ถ้าวางไฟล์เอเจนต์ไว้ข้าง ๆ ตัวติดตั้ง ไฟล์นั้นจะถูกใช้ก่อนไฟล์ที่ฝังมา ใช้วิธีนี้เปลี่ยนกลุ่มอุปกรณ์หรืออัปเดตเอเจนต์ได้โดยไม่ต้องสร้าง `.exe` ใหม่

ชุดนี้ใช้ซ้ำได้กับทุกเครื่อง ไม่มีกำหนดจำนวน และไม่ต้องทำใหม่เมื่อเพิ่มหน่วยงาน เพราะย้ายเครื่องข้ามห้องทีหลังได้

## แก้ข้อความหรือโลโก้ในตัวติดตั้ง

ตัวติดตั้งคอมไพล์มาจาก `src/Setup.cs` โลโก้มาจาก `hospital/brand/logo.png` แก้ไฟล์ใดไฟล์หนึ่งแล้วสร้างใหม่ด้วย

```powershell
npm run build:setup-exe
```

ใช้ตัวคอมไพล์ที่ติดมากับ Windows อยู่แล้ว ไม่ต้องติดตั้งเครื่องมือเพิ่มและไม่ต้องต่ออินเทอร์เน็ต

## ขั้นตอนที่เครื่องลูก

กดสองครั้งที่ `SCP-Remote-Setup.exe` แล้วตอบ **ใช่** ที่หน้าต่างขอสิทธิ์ของ Windows จากนั้นกดตามหน้าจอ

| หน้า | ทำอะไร |
| --- | --- |
| **ยินดีต้อนรับ** | กด **ถัดไป** |
| **คำขออนุญาต** | อ่าน ติ๊กช่องยินยอม แล้วกด **ถัดไป** ปุ่มจะกดไม่ได้จนกว่าจะติ๊ก |
| **ตั้งชื่อเครื่อง** | ใส่ชื่อเครื่องของ Windows ไว้ให้แล้ว แก้เป็นชื่อที่ต้องการหรือกด **ติดตั้ง** ต่อได้เลย |
| **กำลังติดตั้ง** | รอจนเสร็จเอง ไม่ต้องกดอะไร |
| **เสร็จสิ้น** | กด **เสร็จสิ้น** เพื่อปิด |

ย้อนกลับไปแก้ได้ตลอดด้วยปุ่ม **ย้อนกลับ** ก่อนกดติดตั้ง

**ชื่อเครื่อง** คือชื่อที่ฝ่ายไอทีจะเห็นในระบบ เช่น เลขครุภัณฑ์ ห้อง หรือชื่อจุดบริการ พิมพ์ภาษาไทยได้และไม่จำกัดความยาว ตั้งชื่อที่สื่อว่าเครื่องอยู่ที่ไหนจะช่วยให้ตามหาเครื่องได้เร็วตอนมีปัญหา

เครื่องจะขึ้นในระบบภายในไม่กี่นาที โดยใช้ชื่อที่ตั้งไว้

## จัดกลุ่มหลังติดตั้ง

ที่หน้าเว็บ เปิดกลุ่ม **เครื่องใหม่** ติ๊กเลือกเครื่องที่ต้องการ แล้วใช้ **การดำเนินการกลุ่ม** เลือก **ย้ายไปกลุ่มอุปกรณ์** และเลือกกลุ่มปลายทาง เครื่องจะย้ายโดยไม่ต้องแตะเครื่องลูกอีก และไม่ต้องติดตั้งใหม่

## ถ้าต้องแก้ชื่อเครื่อง หรืออัปเดตหน้าตาให้เครื่องเก่า

เปิด `SCP-Remote-Setup.exe` ซ้ำได้เลย กดผ่านไปจนถึงหน้าตั้งชื่อ ใส่ชื่อใหม่แล้วกดติดตั้ง ตัวช่วยจะตรวจพบว่ามีโปรแกรมอยู่แล้ว จึงไม่ติดตั้งซ้ำ แต่จะเปลี่ยนชื่อเครื่องให้ และเขียนสีของกล่องขออนุญาตให้เป็นสีโรงพยาบาลด้วย

ใช้วิธีนี้กับเครื่องที่ติดตั้งไว้ก่อนหน้าได้ ไม่ต้องถอนโปรแกรมแล้วติดตั้งใหม่

## ถ้าเครื่องไม่ขึ้นในระบบ

**ที่เครื่องลูก ให้กด `Check-Network.cmd` ก่อนเสมอ** จะบอกสองอย่างที่ต้องรู้ คือเครื่องนี้อยู่วงเครือข่ายอะไร และวิ่งถึงเซิร์ฟเวอร์หรือไม่ พร้อมคัดลอกผลไว้ในคลิปบอร์ดให้ส่งต่อได้ทันที

ผลที่ได้แยกเป็นสองทาง

**เชื่อมต่อได้** แปลว่าเส้นทางเครือข่ายไม่มีปัญหา เหลือแค่เปิดสิทธิ์ให้วงนั้นที่เครื่องเซิร์ฟเวอร์

```powershell
node scripts/allow-subnet.js add 192.168.30.0/24
npm run service:restart
```

เปลี่ยนเลขวงให้ตรงกับที่ `Check-Network` รายงาน คำสั่งนี้แก้ทั้งรายการอนุญาตและกฎไฟร์วอลล์ให้พร้อมกัน

**เชื่อมต่อไม่ได้** แปลว่าเครื่องยังวิ่งไปไม่ถึงเซิร์ฟเวอร์ ต้องให้ผู้ดูแลระบบเครือข่ายเปิดเส้นทางระหว่างวงให้ก่อน แก้ที่เซิร์ฟเวอร์หรือที่เครื่องลูกเองไม่ได้

ถ้าทั้งสองข้อผ่านแล้วยังไม่ขึ้น ให้ตรวจต่อที่

1. บริการทำงานอยู่หรือไม่ เปิด `services.msc` ที่เครื่องลูก หาบริการที่ชี้ไปยัง `MeshAgent.exe`
2. บันทึกฝั่งเซิร์ฟเวอร์ที่ `scripts/daemon/scpremote.out.log`

## ถอนการติดตั้ง

ที่เครื่องลูก ไปที่ **ตั้งค่า > แอป** แล้วถอน **SCP-Remote** ออก หรือสั่งจากหน้าต่างคำสั่งแบบผู้ดูแลเครื่อง

```
"C:Program FilesSCP-Remotescpremote.exe" -fulluninstall
```

เครื่องที่ติดตั้งไว้ก่อนเปลี่ยนชื่อ จะยังอยู่ที่ตำแหน่งเดิม ใช้คำสั่งนี้แทน

```
"C:Program FilesMesh AgentMeshAgent.exe" -fulluninstall
```

## ข้อจำกัดที่ยังไม่ได้ทดสอบ

ทุกหน้าของตัวช่วย การตั้งชื่อ และการเขียนไฟล์ชื่อเครื่อง ตรวจอัตโนมัติแล้ว และการตั้งชื่อผ่านการใช้งานจริงมาแล้วหนึ่งเครื่อง
