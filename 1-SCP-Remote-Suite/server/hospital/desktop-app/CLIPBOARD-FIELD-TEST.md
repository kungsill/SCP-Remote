# ใบทดสอบภาคสนาม: ภาพรีโมตและ copy/วาง

ใช้ทดสอบกับเครื่องจริงสองเครื่อง (เครื่องช่าง + เครื่องลูกที่มีคนนั่งอยู่เพื่อกดอนุญาต) หลังนำรุ่น 12 พ.ย. 2569 ขึ้นใช้งาน ทำทั้งผ่าน **เว็บ** และผ่าน **โปรแกรม SCP-Remote** ข้อไหนไม่ผ่านให้จดอาการ เวลา และชื่อเครื่อง แล้วแจ้งเพื่อแก้ทีละข้อ

เครื่องช่าง: ____________ เครื่องลูก: ____________ วันที่: ____________ ผู้ทดสอบ: ____________

| ก2 | แถบสถานะมุมบนซ้าย | ตัวเลือกอยู่ที่ **คมชัดสูงสุด** | ☐ | ☐ |
| ก3 | จดค่า KB/s ขณะเลื่อนหน้าจอเครื่องลูก ที่ "คมชัดสูงสุด" แล้วเปลี่ยนเป็น "คมชัด" จดอีกครั้ง | ทั้งสองระดับใช้งานได้ลื่น จดตัวเลข: ______ / ______ KB/s | ☐ | ☐ |

| ก5 | จอเครื่องลูกใหญ่กว่าหน้าต่างรีโมต | ภาพถูกย่อให้เห็นทั้งจอ กดปุ่ม 1:1 แล้วคมและเลื่อนดูได้ | ☐ | ☐ |
| ก6 | คลิกปุ่มเล็ก ๆ ที่มุมจอทั้งสี่ และกลางจอ | เมาส์ลงตรงจุดที่คลิกทุกครั้ง | ☐ | ☐ |
| ก7 | ย่อ/ขยายหน้าต่างรีโมต แล้วคลิกซ้ำ | ภาพจัดขนาดใหม่ เมาส์ยังตรง | ☐ | ☐ |
| ก8 | เลือกระดับอื่น ปิดรีโมต แล้วเปิดใหม่ | ตัวเลือกยังเป็นระดับที่เลือกไว้ | ☐ | ☐ |
