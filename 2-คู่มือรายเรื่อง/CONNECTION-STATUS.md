# สถานะการเชื่อมต่อและเวอร์ชันเครื่องลูก

หน้า Desktop แสดงขั้นตอนจากเหตุการณ์เชื่อมต่อจริง: ติดต่อเซิร์ฟเวอร์ รอเครื่องลูก รอผู้ใช้อนุญาต เชื่อมต่อแล้ว และการปฏิเสธหรือข้อผิดพลาดที่เครื่องลูกส่งกลับ การเชื่อมต่อสำเร็จหมายถึงช่องทางรีโมตเปิดแล้ว ไม่ใช่การรับรองว่าภาพหรือโปรแกรมปลายทางทำงานถูกต้องทั้งหมด

หากไม่มีความคืบหน้า 90 วินาที จะแสดงปุ่มลองเชื่อมต่อใหม่ ไม่เชื่อมต่อซ้ำเอง ปุ่มนี้ใช้กับการรีโมตผ่านเอเจนต์เครื่องเดิมเท่านั้น การลองใหม่จะปิดช่องทางเก่าก่อน และยังใช้สิทธิ์กับนโยบายอนุญาตเดิม ข้อผิดพลาดจะแสดงเป็นข้อความธรรมดา

ในแดชบอร์ด ใต้ชื่อเครื่องแสดงเวอร์ชันโมดูล SCP-Remote ที่เอเจนต์รายงาน เทียบกับเวอร์ชันเซิร์ฟเวอร์ เลื่อนเมาส์บนข้อความเพื่อดูเวลารายงานล่าสุด เครื่องออฟไลน์แสดงเป็นข้อมูลครั้งล่าสุด เครื่องที่ยังไม่รายงานไม่ถือว่าอัปเดตแล้ว ไม่มีการสั่งอัปเดตหรือรีสตาร์ตเครื่องลูกจากป้ายนี้

เลขรุ่นอยู่ใน `hospital/release.json` และ `meshCoreObj.scpRelease` ใน `agents/meshcore.js` เมื่อออกรุ่นโมดูลใหม่ต้องเปลี่ยนทั้งสองจุดให้ตรงกัน มีการทดสอบตรวจความตรงกัน เลขรุ่นนี้แยกจากรุ่นไฟล์ติดตั้ง MeshAgent และไม่ใช่หลักฐานตรวจความสมบูรณ์ของไบนารี

รองรับไทยและอังกฤษในหน้า Desktop และแดชบอร์ดหลัก หลังอัปเดตให้โหลดหน้าใหม่ด้วย Ctrl+F5 เครื่องลูกจะรายงานเมื่อเชื่อมต่อและโหลด core ใหม่
