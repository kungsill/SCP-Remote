# หน้าต่างขออนุญาตและหน้าดูหลายเครื่อง

ค่าที่ปรับล่าสุดตามคำขอ: ปิด `userConsentFlags.desktopprivacybar` เพื่อซ่อนแถบแชร์หน้าจอด้านบน โดยยังเปิด `desktopnotify` และ `desktopprompt` การเชื่อมต่อใหม่จะใช้ค่านี้ หากกลุ่มอุปกรณ์หรือบัญชีตั้งบังคับแถบไว้แยกต่างหาก นโยบายนั้นยังมีผล

## หน้าต่างบนเครื่องลูก Windows

บัญชีผู้ดูแลที่ระบุใน `domains[""].unattendedAdmins` เช่น `["user//admin"]` เข้า Desktop, Terminal และไฟล์ได้โดยไม่ต้องกดอนุญาต ต้องเป็นผู้ดูแลสิทธิ์สูงสุด (`siteadmin: 4294967295`) ในโดเมนเดียวกันเท่านั้น ไม่ใช้ข้อยกเว้นนี้กับลิงก์แขก และยังคงการแจ้งเตือนกับสิทธิ์เข้าถึงอุปกรณ์ ค่าเริ่มต้นเมื่อไม่กำหนดรายการนี้คือไม่มีข้อยกเว้น

แก้การส่งคำตอบจากหน้าต่างขออนุญาต: รอให้บริการยืนยันว่าได้รับคำตอบก่อนปิดโปรเซสหน้าต่าง หากหน้าต่างปิดผิดปกติหรือไม่ตอบกลับ จะยุติคำขอแทนการรอไม่สิ้นสุด โดยไม่อนุญาตอัตโนมัติ

ปรับหน้าต่างให้ใช้พื้นสว่าง ตัวอักษรเข้ม รูปผู้ขอขนาดเล็ก แสดงชื่อผู้ขอแยกจากคำอธิบาย และเพิ่มขนาดปุ่ม **อนุญาต / ปฏิเสธ** คำอธิบายระบุว่าผู้ขอจะทำอะไรได้ เช่น การเข้าถึงไฟล์สามารถดู ดาวน์โหลด อัปโหลด และลบไฟล์ได้

ค่าเริ่มต้นเป็นภาษาไทยแม้ Windows ใช้ภาษาอังกฤษ ตั้งค่าที่ `domains[""].consentMessages`: `Language` รองรับ `th` / `en` สำหรับปุ่มและข้อความพื้นฐาน ส่วน `Desktop`, `Terminal`, `Files` เป็นข้อความที่กำหนดเอง ใช้ `{0}` แทนชื่อผู้ขอ หากเปลี่ยนเป็นอังกฤษให้เปลี่ยนข้อความกำหนดเองเหล่านี้ด้วย `BackgroundColor` / `ForegroundColor` เป็นสีเฉพาะหน้าต่างขออนุญาต ไม่เปลี่ยนสีตัวติดตั้ง

หน้าต่างใช้ฟอนต์ Leelawadee UI ของ Windows เพื่อรองรับภาษาไทยบนเครื่องที่ยังไม่มี Sarabun ส่วนเว็บยังใช้ Sarabun ตามเดิม ปุ่มปฏิเสธ ปุ่มปิด และการหมดเวลาไม่ได้ให้สิทธิ์เข้าถึงเครื่อง การอนุญาตอัตโนมัติ 5 นาทีเป็นตัวเลือกที่ผู้ใช้ต้องเลือกเอง และใช้กับผู้ขอคนเดิม

ไฟล์หลักคือ `agents/modules_meshcore/win-scp-userconsent.js` (หน้าต่าง Windows) และ `agents/modules_meshcore/coretranslations.json` (ข้อความ) โค้ดหน้าต่างพัฒนาจาก [MeshAgent win-userconsent.js](https://github.com/Ylianst/MeshAgent/blob/master/modules/win-userconsent.js) ภายใต้ Apache-2.0 และคงประกาศลิขสิทธิ์ต้นฉบับไว้

## หน้าดูหลายเครื่อง

หน้าต่างแจ้งข้อความใช้ `win-scp-dialog.js` แยกจากหน้าต่างอนุญาต รองรับ OK, กากบาท และ Alt+F4 โดยสั่งปิดหน้าต่างก่อนส่งผลกลับบริการ รอยืนยันรับผลก่อนออกจากโปรเซส และล้างสถานะข้อความเมื่อจบหรือผิดพลาด เพื่อไม่ให้คำขอถัดไปติดสถานะเก่า โมดูลนี้พัฒนาจาก `win-dialog` ของ MeshAgent โดยคงใบอนุญาต Apache-2.0 เดิม

เปิดหน้าดูหลายเครื่องแล้วกดเริ่มแสดงภาพ ระบบจะเปิดภาพเมื่อผู้ใช้สั่งเท่านั้น เมื่อหยุดหรือออกจากหน้า จะปิดการเชื่อมต่อภาพ ไม่เชื่อมต่อซ้ำอัตโนมัติหลังถูกปฏิเสธ

ภาพแบบดูอย่างเดียวไม่รับเมาส์ คีย์บอร์ด Ctrl+Alt+Del หรือคำสั่งล็อกเครื่องจากช่องทางภาพ แต่ยังปรับความละเอียด คุณภาพภาพ รีเฟรช และเลือกจอได้ การเข้ารีโมตควบคุมผ่านหน้าอุปกรณ์เป็นคนละการเชื่อมต่อและยังใช้การขออนุญาตเดิม

`desktopViewOnlyNoPrompt: true` ใช้ข้ามเฉพาะคำขอเปิดภาพในช่องทางดูอย่างเดียว การแจ้งเตือนและแถบแชร์หน้าจอยังคงตามนโยบายที่ตั้งไว้ ไม่ข้ามคำขอเทอร์มินัลหรือไฟล์ หากเปิด `desktopMultiplex` จะคงการขออนุญาตสำหรับช่องทางร่วม และบังคับสิทธิ์ดูอย่างเดียวแยกตามผู้ชม

หลังอัปเดตเซิร์ฟเวอร์ ให้โหลดหน้าเว็บใหม่ด้วย Ctrl+F5 เอเจนต์ที่เชื่อมต่อใหม่จะตรวจและรับ core จากเซิร์ฟเวอร์ เครื่องที่ออฟไลน์ต้องรอเชื่อมต่อกลับมา โดยไม่จำเป็นต้องถอนแล้วติดตั้งใหม่สำหรับการเปลี่ยนแปลงนี้

## การตรวจสอบ

ทดสอบการเปิดโมดูลและหน้าต่างตัวอย่างด้วย MeshAgent บนเครื่องพัฒนาแล้ว หน้าต่างตัวอย่างปิดด้วย `TIMEOUT` โดยไม่มีการเชื่อมต่อรีโมต ทดสอบอัตโนมัติครอบคลุมการปิดภาพเมื่อออกจากหน้า การรับ/ปฏิเสธข้อมูลภาพ การบล็อกอินพุตและล็อกเครื่อง และการคงคำขออนุญาตของการควบคุมปกติ ยังต้องทดสอบการดูหลายเครื่องจริงและการกดอนุญาต/ปฏิเสธจากผู้ใช้เครื่องลูกในเครือข่ายโรงพยาบาล
