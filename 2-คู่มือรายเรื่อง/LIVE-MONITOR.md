# กราฟภาพรวมและสถานะเครื่องสด

รุ่น `2026.09.16.6` เพิ่มแถบความคืบหน้าและรายการขั้นตอน 1–4 ทั้งงานล้างไฟล์และไดรเวอร์ เปอร์เซ็นต์รวมแบ่งน้ำหนักเท่ากันขั้นละ 25% และระบุว่าเป็นเปอร์เซ็นต์ตามขั้นตอน ไม่ใช่เวลา/จำนวนไบต์ เมื่อรู้จำนวนรายการจะมีเปอร์เซ็นต์ย่อยจากจำนวนที่ดำเนินการแล้วเทียบจำนวนทั้งหมด ขั้นค้นหาและสำรวจที่ยังไม่รู้จำนวนรวมจะแจ้งตรง ๆ ไม่เดินเปอร์เซ็นต์ตามเวลา 100% ต้องมีผลสุดท้ายยืนยันเสร็จ งานที่หยุดเมื่อถึงขีดจำกัดจะไม่ขึ้น 100%

ล้างไฟล์ใช้สองช่วง: รวบรวมรายการที่เข้าเงื่อนไข แล้วตรวจพาธและอายุไฟล์ซ้ำก่อนลบ คงข้อจำกัด 120 วินาทีและ 100,000 รายการ ไดรเวอร์ดาวน์โหลดและติดตั้งทีละรายการเพื่อรายงานจำนวนจริง โดยไม่รีสตาร์ตเครื่องอัตโนมัติ งานที่เริ่มด้วยสคริปต์รุ่นเก่าอาจแสดงได้เฉพาะขั้นตอนเดิม ไม่มีจำนวนรายการย้อนหลัง

แดชบอร์ดแสดงกราฟจำนวนเครื่องออนไลน์/ออฟไลน์ แยกหน่วยงาน และสถานะงานล้างไฟล์ กด **สถานะเครื่อง / Task Manager** ที่แถวเครื่อง หรือ **ดูกราฟสด / Task Manager** ในภาพรวมเพื่อเปิดหน้ารายเครื่อง

อ่าน CPU/RAM ทุก 5 วินาทีและรายการโปรเซสทุก 10 วินาทีขณะเปิดหน้าต่างและแท็บมองเห็น หยุดเมื่อปิดหน้าต่าง เก็บกราฟไว้สูงสุด 60 จุดในหน้านี้ ไม่ได้เก็บประวัติย้อนหลังบนเซิร์ฟเวอร์ ช่องว่างหรือเครื่องไม่ตอบไม่ถูกแทนด้วย 0

พื้นที่ว่างดิสก์เป็นรายงานสเปกล่าสุด ไม่ใช่กราฟอัตราอ่าน/เขียนดิสก์สด รายการโปรเซสแสดง PID ชื่อ และผู้ใช้ กดรายละเอียดเพื่อขอข้อมูลที่เอเจนต์รองรับ ไม่แสดง CPU/RAM รายโปรเซสที่ไม่มีข้อมูล และไม่มีปุ่มฆ่าโปรเซสในหน้านี้

การล้างไฟล์แสดงส่งคำสั่ง → เตรียมงาน → ตรวจ/ล้าง Windows Temp → ตรวจ/ล้าง Temp ผู้ใช้ → วัดพื้นที่ว่างและสรุปผล พร้อมจำนวนรายการที่ตรวจและลบจริง ช่วงสำรวจยังไม่ทราบจำนวนรวม ส่วนช่วงล้างจะแสดงเปอร์เซ็นต์จากรายการที่นับแล้วตามรุ่นใหม่ด้านบน เอเจนต์รุ่น `2026.09.16.5` ขึ้นไปส่งความคืบหน้าระหว่างทำงาน ผลล่าสุดเก็บในฐานข้อมูล `scpcleanup` และอ่านกลับตามสิทธิ์เข้าถึงเครื่อง

โปรเซสรุ่นเดิมที่ยังไม่ส่ง tag กลับจะไม่แสดงในหน้าจอใหม่นี้จนได้รับ core ใหม่ เพื่อไม่เอาคำตอบคนละหน้าต่างมาปะปน หากไม่ได้รับความคืบหน้าการล้างนาน 3 นาที จะแสดงว่ายังยืนยันผลไม่ได้ ผล “เสร็จแล้ว” ต้องมาจากคำตอบสุดท้ายเท่านั้น

ตรวจบน `test01` รุ่น `2026.09.16.5` แล้ว: ได้ค่า CPU/RAM จริงและรายการ 196 โปรเซส ณ เวลาทดสอบ กราฟมีการอัปเดตหลายรอบ ตรวจช่องทาง progress ด้วยคำสั่งแสดงข้อความทดสอบที่ไม่ลบไฟล์ ได้ทั้งข้อความ progress และผลจบคำสั่ง โดยใช้รหัสทดสอบที่ไม่บันทึกเป็นผลล้างจริง
