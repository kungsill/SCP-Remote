# SCP-Remote Suite

ชุดดูแลคอมพิวเตอร์สำหรับ **โรงพยาบาลสีชมพู** รวมระบบรีโมต เครื่องมือดูแลเครื่อง และคู่มือภาษาไทย เผยแพร่เพื่อการศึกษาและนำไปปรับใช้กับหน่วยงานของคุณ

พัฒนาและดูแลโดยทีมไอที โรงพยาบาลสีชมพู — **[kungsill](https://github.com/kungsill)**

## ในชุดนี้มีอะไร

| รายการ | ตำแหน่ง |
| --- | --- |
| **SCP-Remote** — เว็บรีโมต แดชบอร์ด ผังโรงพยาบาล ตรวจสุขภาพเครื่อง และงานซ่อม | [เซิร์ฟเวอร์](1-SCP-Remote-Suite/server/) |
| **SCPclear** — ทำความสะอาดและปรับแต่งเครื่อง พร้อมชุดฟอนต์ไทย | [SCPclear-plus](1-SCP-Remote-Suite/tools/SCPclear-plus/) |
| **SCPPrint** — แชร์เครื่องพิมพ์ผ่านพอร์ต 9100 ในวง LAN พร้อมตัวติดตั้ง | [SCPPrint](1-SCP-Remote-Suite/tools/SCPPrint/) |
| ตัวช่วยติดตั้งทั้งชุดบน Windows | [START-HERE.cmd](1-SCP-Remote-Suite/START-HERE.cmd) |
| คู่มือฉบับสมบูรณ์ | [PDF](คู่มือ-SCP-Remote-ฉบับสมบูรณ์.pdf) · [HTML สำหรับดาวน์โหลดแล้วเปิด](คู่มือ-SCP-Remote-ฉบับสมบูรณ์.html) |
| คู่มือแยกตามเรื่อง | [คู่มือรายเรื่อง](2-คู่มือรายเรื่อง/) |

## ติดตั้งแบบพร้อมใช้

1. กด **Code → Download ZIP** บน GitHub แล้วแตกไฟล์
2. เปิดโฟลเดอร์ `1-SCP-Remote-Suite`
3. ดับเบิลคลิก **`START-HERE.cmd`** และอนุญาตสิทธิ์ผู้ดูแลระบบ
4. ทำตามตัวช่วยติดตั้ง: ตรวจ Node.js, ติดตั้งแพ็กเกจ, สร้างหน้าเว็บภาษาไทย และสร้างทางลัดของเครื่องมือ
5. เลือกว่าจะให้ SCP-Remote เริ่มอัตโนมัติเมื่อเปิดเครื่องหรือไม่ แล้วเปิด **https://127.0.0.1:8443**
6. สร้างบัญชีแรกเป็นผู้ดูแลระบบ จากนั้นสร้างกลุ่มอุปกรณ์และดาวน์โหลดเอเจนต์ไปติดตั้งบนเครื่องลูก

ดูรายละเอียดตัวช่วยติดตั้งใน [คู่มือ Suite](1-SCP-Remote-Suite/README.md) และ [อ่านก่อน](อ่านก่อน.txt)

## ติดตั้งเซิร์ฟเวอร์ด้วยตนเอง

ต้องมี **Node.js 20 ขึ้นไป** เปิด PowerShell ในโฟลเดอร์ที่แตกไฟล์แล้ว:

```powershell
cd 1-SCP-Remote-Suite/server
npm ci
npm run build:hospital
npm run start:hospital
```

หากต้องการติดตั้งเป็นบริการ Windows ให้เปิด PowerShell ด้วยสิทธิ์ผู้ดูแลระบบในโฟลเดอร์ `server` แล้วรัน:

```powershell
npm run service:install
```

การตั้งชื่อหรือ IP เซิร์ฟเวอร์ วงเครือข่าย สิทธิ์ผู้ใช้ และ HTTPS อยู่ใน [คู่มือเซิร์ฟเวอร์ภาษาไทย](1-SCP-Remote-Suite/server/README-TH.md) และ [คู่มือดูแลระบบ](1-SCP-Remote-Suite/server/hospital/README.md)

- เริ่มอ่านภาพรวมและกระบวนการใช้งานจาก [คู่มือฉบับสมบูรณ์ PDF](คู่มือ-SCP-Remote-ฉบับสมบูรณ์.pdf)
- คู่มือรายฟีเจอร์อยู่ใน [โฟลเดอร์คู่มือรายเรื่อง](2-คู่มือรายเรื่อง/) และ [server/hospital](1-SCP-Remote-Suite/server/hospital/)

- แจ้งปัญหาหรือเสนอความสามารถได้ที่ [Issues ของ SCP-Remote](https://github.com/kungsill/SCP-Remote/issues)
