# แจ้งเตือนเชิงรุก (Alert) — ตัวเชื่อมที่ยังไม่ได้ต่อ

ระบบมี "ตัวเชื่อม" สำหรับแจ้งเตือนเมื่อ**เครื่องที่เฝ้าระวังหลุดออฟไลน์** ติดตั้งไว้พร้อมใช้ **แต่ยังไม่ได้ต่อสายออกไปไหน** — จนกว่าจะตั้ง URL ปลายทาง มันจะ**เงียบสนิท** (ไม่อ่านฐานข้อมูล ไม่ส่งอะไร)

## วิธีทำงาน (เมื่อต่อแล้ว)

1. ผู้ดูแลกดปุ่ม **🔕 เฝ้าระวัง** ที่แถวเครื่องในแดชบอร์ด เพื่อติดธงเครื่องสำคัญ (เช่น เครื่องเวชระเบียน เซิร์ฟเวอร์) ให้เป็น **🔔 เฝ้าระวังอยู่**
2. ตัวเชื่อมตรวจทุก ~3 นาที: ถ้าเครื่องที่ติดธง**เคยออนไลน์แล้วหลุดเกิน 30 นาที** → ยิงแจ้งเตือน
3. เครื่องที่**ไม่ติดธง**ไม่ถูกเตือนเลย (เครื่องปิดหลังเลิกงานปกติจึงไม่เด้ง — ไม่ noise)
4. เตือนครั้งเดียวต่อเหตุการณ์ จนกว่าเครื่องจะกลับมา แล้วจึงเตือนใหม่ได้

## วิธีต่อสาย (ทำเมื่อพร้อม)

ตั้งค่าใน config ของเซิร์ฟเวอร์ (`.local/scp-remote/config.json` ที่ `settings`):

```json
"settings": {
  "scpAlertWebhook": "https://ปลายทางของคุณ/hook"
}
```

แล้ว **รีสตาร์ตเซิร์ฟเวอร์** ตัวเชื่อมจะเริ่มทำงานทันที

**ปลายทางรับอะไร:** HTTP POST เป็น JSON เช่น
```json
{ "source": "SCP-Remote", "type": "offline", "computer": "OPD 4",
  "message": "เครื่อง OPD 4 ออฟไลน์เกิน 120 นาที", "at": "2026-09-21T..." }
```

รองรับปลายทางอะไรก็ได้ที่รับ JSON POST — LINE Bot (Messaging API), Discord/Slack webhook, หรือสคริปต์ของคุณเอง

## หมายเหตุความเป็นส่วนตัว

ตราบใดที่ยังไม่ตั้ง `scpAlertWebhook` **ไม่มีข้อมูลชื่อเครื่อง/สถานะออกนอกโรงพยาบาลเลย** การต่อสายคือการตัดสินใจที่ต้องทำเอง

## โค้ด

- `public/scripts/scp-dashboard.js` — ปุ่ม 🔔 เฝ้าระวัง
- ต่อเข้า server ที่ `meshcentral.js` (สร้าง + start ตอนบูต แบบ dormant)
