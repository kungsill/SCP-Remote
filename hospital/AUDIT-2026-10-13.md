ตรวจจากโค้ดใน workspace, เซิร์ฟเวอร์ที่พอร์ต 8443, Chrome จำลอง 390/1440px, เทสต์ระบบ และไฟล์สำรอง ณ ประมาณ 16:17 น. เป็นการตรวจฟังก์ชันและ UI ตามขอบเขตด้านล่าง ไม่ใช่การรับรองความปลอดภัยทุก endpoint หรือผลการรีโมตกับเครื่องจริง

**อัปเดตตามคำสั่งเพิ่มเติม:** ข้อ 4 เพิ่มการบันทึกประมาณการกลางในใบแจ้งซ่อมแล้ว มีสิทธิ์เข้าถึงตามเครื่อง ฉบับ/ผู้บันทึก/เวลา ประวัติยอดรวม และตรวจ revision ร่วมกับการปรับสถานะซ่อม ทดสอบเปิดจากเบราว์เซอร์ใหม่และแก้ไขพร้อมกันผ่าน ข้อ 3 ค้นต้นฉบับเพิ่มและเก็บผลใน `reference-price-research.json` ยังไม่ยืนยันฉบับเกณฑ์ทั่วไปปี 2551–2552 และ 2554; รายละเอียดอยู่ [REFERENCE-PRICE-ARCHIVE.md](F:/Antigravity/sichomphu-remote/hospital/REFERENCE-PRICE-ARCHIVE.md) ผลตรวจเดิมด้านล่างเก็บไว้เป็นหลักฐานก่อนแก้

**การตรวจและนำขึ้นใช้รอบเพิ่มเติม:** build Thai/English ผ่าน เทสต์ระบบ 550 รายการผ่าน ตรวจ Chrome 320/390/1440px ไม่มีกรอบประมาณการล้น ตรวจ PDF ตัวอย่าง 1 หน้า ไม่มีหน้าปกว่าง ตรวจการเปิดจากอีก tab และบันทึก revision ผ่านโดยใช้ฐานข้อมูลจำลอง ไม่สร้างใบงานทดสอบในฐานข้อมูลจริง Restart เฉพาะ Windows service `scpremote.exe` แล้ว โปรเซสเดิม 53680 หยุดและพอร์ต 8443 ว่างก่อน start โปรเซสใหม่ 48788 ทำงาน พอร์ต/HTTP routing/ไฟล์ JS และ catalog ฉบับปัจจุบันตอบ 200 ไม่หยุด Cloudflared ข้อ 6 ฝั่งเซิร์ฟเวอร์โหลดในการ restart รอบนี้แล้ว

## จุดที่ควรแก้ก่อน

### 1. แดชบอร์ดเว็บเต็มกว้างเกินหน้าจอมือถือ

**ยืนยันข้อผิดพลาด:** จอจำลองกว้าง 390px แต่หน้าเอกสารกว้าง 495px และขอบขวาแดชบอร์ดอยู่ที่ 483px ทำให้ข้อความ ปุ่ม และการ์ดด้านขวาถูกตัด ตรงกับภาพผู้ใช้ หน้าเลือกเครื่อง `/m` ผ่านการตรวจจอเล็กแล้ว แต่หน้าเว็บเต็มยังมีข้อจำกัดนี้

สาเหตุหลัก: [default.handlebars](F:/Antigravity/sichomphu-remote/views/default.handlebars:90) ยังตั้ง `min-width:495px` ที่ body ควรปรับกรอบของแดชบอร์ดให้ตาม viewport บนมือถือ พร้อมตรวจเมนู ตาราง หน้าตั้งค่า และหน้ารีโมต เพื่อไม่ให้การแก้กรอบกระทบ canvas รีโมต

### 2. สีการ์ดสรุปในโหมดมืดยังอ่านยาก

**ยืนยันข้อผิดพลาด:** หัวเว็บ SCP-Remote แก้แล้ว แต่การ์ดตัวเลขยังใช้พื้น `rgba(255,255,255,.9)` ขณะที่ข้อความใน night mode เป็นสีสว่าง ตัวอย่างจำนวนเครื่องทั้งหมด/เครื่องปิดและคำบรรยายจึงจาง ควรเปลี่ยนพื้นและขอบเป็นตัวแปรธีม

จุดต้นเหตุ: [scp-dashboard.css](F:/Antigravity/sichomphu-remote/public/styles/scp-dashboard.css:23), สีคำบรรยายอยู่บรรทัด 47 ภาพตรวจอยู่ `.local/ui-review/app-audit/dashboard-390-dark.png` และ `dashboard-1440-dark.png`

**ปรับเพิ่มเติม:** คลังราคากลางยังเป็นหน้าต่างสีขาวทั้งสองโหมด ข้อความตัดกับพื้นอ่านได้ แต่ยังไม่ตาม dark mode หน้าเว็บเต็มยังโหลด IBM Plex ผ่าน Google Fonts ต่างจาก `/m` ที่โหลดฟอนต์ในเครื่อง ควรใช้ฟอนต์ท้องถิ่นและตัวแปรธีมให้สม่ำเสมอ

## จุดที่ขาดด้านข้อมูลและงานซ่อม

### 3. ราคาย้อนหลังยังไม่พบต้นฉบับครบทุกปี

คลังมี 18 ฉบับ / 973 รายการตามฉบับเอกสาร เลือกปีงบ 2551–2570 ได้ แต่ยังไม่มีต้นฉบับยืนยันปี 2551–2552 ส่วนปี 2554 พบฉบับ GIS แยกจากเกณฑ์ทั่วไป จึงไม่ควรถือว่าพบประกาศครบทุกปีในช่วง 20 ปี

ร่างงบ 2570 แยกจากประกาศจริงในคลังแล้ว ค่าเริ่มต้นงบซื้อทดแทนในเกณฑ์ประเมินยังใช้ร่างตามคำสั่งเดิมของผู้ดูแล ถ้าต้องการเปลี่ยนฉบับจากหน้าเกณฑ์ ควรเพิ่มตัวเลือกฉบับอ้างอิงโดยตรง รายละเอียดอยู่ [REFERENCE-PRICE-ARCHIVE.md](F:/Antigravity/sichomphu-remote/hospital/REFERENCE-PRICE-ARCHIVE.md)

### 4. ประมาณการซ่อมยังไม่ได้เก็บในฐานข้อมูลกลาง

**ข้อจำกัดการใช้งาน:** ใบประมาณการบันทึกใน localStorage ของเบราว์เซอร์นั้น ไม่ได้ผูกกับใบแจ้งซ่อมหรือบัญชีผู้ใช้ในฐานข้อมูล จึงไม่ส่งต่ออัตโนมัติเมื่อใช้มือถือ/คอมพิวเตอร์อีกเครื่อง ถ้าจะใช้ร่วมทีมควรเพิ่มการบันทึกกลางและผูกกับใบงาน

ตำแหน่งปัจจุบัน: [scp-price-archive.js](F:/Antigravity/sichomphu-remote/public/scripts/scp-price-archive.js:100)

## การตั้งค่าและงานที่ควรทำตามขั้นตอน

### 5. ตรวจ MFA และการตั้งค่า proxy ให้ตรงกับการเข้าใช้ผ่านโดเมน

- ตัวตรวจ config พบว่า admin ยังไม่ลงทะเบียน 2FA และไม่ได้บังคับ `force2factor`
- ตรวจ HEAD หน้าเว็บหลัก `https://remote.kpsnana.com/` แบบไม่มี session ได้ 302 ไปหน้า Cloudflare Access จึงมีด่าน Access สำหรับหน้าเว็บหลัก ไม่ได้สรุปว่าเปิดหน้าเว็บโดยไม่มีการป้องกัน และไม่ได้ทดสอบทุกเส้นทางของโดเมน
- `trustedProxy` ยังไม่ได้กำหนด ขณะที่มีการใช้งานผ่านโดเมน ตัวตรวจ config ปัจจุบันจึงยังจัดสภาพนี้เป็น LAN จาก allowlist ต้องทบทวนการตรวจ tunnel/proxy และการบันทึก IP ผู้ใช้จริง
- ควรลงทะเบียน MFA ก่อนเปลี่ยนนโยบายบังคับ การตั้ง proxy ต้องพิจารณา allowlist และ Cloudflare Access พร้อมกัน ไม่ได้เปลี่ยน config หรือนโยบายเข้าสู่ระบบในรอบนี้

หลักฐานการตรวจ: [check-config.js](F:/Antigravity/sichomphu-remote/scripts/check-config.js:92), การเลือก IP จาก proxy อยู่ [webserver.js](F:/Antigravity/sichomphu-remote/webserver.js:7218)

### 6. ตัวแก้ login ฝั่งเซิร์ฟเวอร์ยังต้องโหลดในการ restart ถัดไป

โปรเซสเซิร์ฟเวอร์เริ่ม 09:28 แต่ `webserver.js` แก้ล่าสุด 09:45 ตัวแก้เส้นทาง render ตรงหลัง login จึงรอ restart ฝั่งเซิร์ฟเวอร์ ขณะนี้ fallback ใน template พากลับ `/m` ได้แล้ว ควรโหลดตัวแก้ฝั่งเซิร์ฟเวอร์ในช่วงบำรุงรักษาที่ไม่ตัดงานรีโมต

## ข้อผิดพลาดที่พบและแก้ในรอบนี้

### รายการประมาณการเกิน 200 บรรทัดถูกตัดตอนเปิดกลับ

เดิมหน้าเพิ่มรายการได้เกิน 200 แต่ตอนโหลดคืนใช้ `saved.lines.slice(0,200)` ทำให้ใบประมาณการ 201 บรรทัดแสดงยอดเพียง 200 บรรทัด และเมื่อแก้ไขต่อจะบันทึกทับโดยไม่มีบรรทัดสุดท้าย

**แก้แล้ว:** อ่านคืนทุกบรรทัดที่บันทึกไว้ เพิ่ม regression test กรณี 201 รายการ เปิดกลับและแก้จำนวนแล้วรายการสุดท้ายยังอยู่ครบ ยอด 20,100 บาทเปลี่ยนเป็น 20,200 บาทตามการแก้จำนวนหนึ่งรายการ เปลี่ยนเวอร์ชันสคริปต์เป็น `20261013-preserve` และ build หน้าไทย/อังกฤษแล้ว

### ชื่อ SCP-Remote จางบนหัวเว็บโหมดมืด

**แก้แล้วในงานก่อนตรวจ:** พื้นหัวเว็บและเมนูด้านข้างเปลี่ยนตามธีม จากกรณีจำลองเดิมความต่างสีชื่อเว็บ 1.05:1 เป็น 14.60:1 ในโหมดมืด ตรวจทั้ง `.night`, `data-bs-theme=dark`, plain title และชื่อที่ถูกห่อด้วย `<font>`

## สิ่งที่ตรวจผ่าน

- เทสต์ระบบ **545 ข้อผ่านทั้งหมด**, build ภาษาไทย/อังกฤษ และ HTTP checks ผ่าน
- `/m`: จอ 320–1440px, โหมดสว่าง/มืด, ค้นหา กรองออนไลน์ ตัวเลือกหน่วยงาน ผัง และ sticky search ตรวจผ่านจากข้อมูลจำลอง
- คลังราคา: เลือก 20 ปีงบ, ราคาประกาศจริง/ร่างแยก, ตัวกรอง AIO, สเปก, รวมเงินประมาณการ และ PDF ตรวจผ่าน
- PDF จำลองชุดปัจจุบัน 70 รายการมี 21 หน้า ถึงรายการท้ายพร้อมหมายเหตุ ไม่มีหน้าปกว่าง ตัวอย่างประมาณการ 2 รายการมียอด 27,400 บาท
- สำรองล่าสุด `meshcentral-autobackup-2026-10-13-02-23.zip` พบทั้ง `F:/EX/scp-remote-backups` และ `H:/SCP-Remote-Backups` SHA-256 ของสองสำเนาตรงกัน ZIP ตรวจ CRC ผ่าน 36 entries ไม่ได้ทำ restore drill ในรอบนี้
- Launcher ที่ตรวจฝัง URL `https://192.168.2.25:8443/` ตรงกับพอร์ตเซิร์ฟเวอร์ ไม่พบข้อผิดพลาดพอร์ตเก่าจากไฟล์นี้

## ขอบเขตที่ยังไม่ได้ทดสอบกับของจริง

ไม่ได้เชื่อมต่อจอเครื่องลูกจริง ส่งคำสั่งแก้ปริ้น ติดตั้งโปรแกรม/ไดรเวอร์ ตัดเครือข่าย หรือ restart เซิร์ฟเวอร์ ไม่ได้ทำ restore จาก backup ผลเทสต์และภาพจำลองจึงยืนยันฟังก์ชันที่ทดสอบ ไม่รับรองเส้นทางรีโมต/งานสั่งเครื่องลูกทุกสภาพเครือข่าย

ไฟล์ตรวจอยู่ `.local/tests/audit-test-results.log`, `.local/ui-review/app-audit/measurements.json` และ `.local/ui-review/mobile-prices/`

**ลำดับถัดไปที่แนะนำ:** แก้แดชบอร์ดมือถือและสีการ์ดสรุปก่อน จากนั้นบันทึกใบประมาณการกลาง/เลือกฉบับเกณฑ์ และจัดการ MFA/proxy กับ restart ตามขั้นตอน
