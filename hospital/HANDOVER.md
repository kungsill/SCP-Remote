# รับช่วงดูแล SCP-Remote

เอกสารนี้เขียนให้คนที่ต้องมารับช่วงดูแลระบบนี้ต่อ โดยไม่เคยแตะมาก่อน อ่านจบแล้วควรดูแลต่อได้ และรู้ว่าอะไรห้ามทำ

> ช่องที่เขียนว่า **`[ กรอก ]`** คือข้อมูลที่ต้องเติมเอง ไม่มีใครเติมแทนได้ **กรุณาเติมให้ครบก่อนที่จะต้องใช้เอกสารนี้จริง**

## ระบบนี้คืออะไร

ระบบรีโมตช่วยเหลือคอมพิวเตอร์ของโรงพยาบาล พัฒนาต่อจาก MeshCentral 1.2.5 เจ้าหน้าที่ไอทีใช้ดูหน้าจอ เข้าควบคุมเครื่อง รับส่งไฟล์ และสั่งปิดเครื่องของผู้ใช้ได้จากที่เดียว

**เข้าใจความเสี่ยงก่อน:** ใครก็ตามที่เข้าระบบนี้ได้ในฐานะผู้ดูแล จะเข้าถึงคอมพิวเตอร์ทุกเครื่องที่ติดตั้งไว้ เห็นหน้าจอ เปิดไฟล์ และสั่งงานได้ทั้งหมด ในโรงพยาบาลนั่นหมายถึงข้อมูลผู้ป่วยด้วย การดูแลบัญชีผู้ดูแลระบบจึงสำคัญกว่าทุกเรื่องในเอกสารนี้

### ถ้าเข้าระบบไม่ได้

หยุดบริการก่อน แล้วรันในโฟลเดอร์โครงการ

```
npm run service:stop
node meshcentral.js --datapath .local/scp-remote --resetaccount admin --pass "รหัสใหม่ที่ต้องการ"
npm run service:start
```

คำสั่งนี้ปลดล็อกบัญชี ตั้งรหัสใหม่ และ**ปิด 2FA ของบัญชีนั้นด้วย** ต้องใช้สิทธิ์บนเครื่องเซิร์ฟเวอร์ — แปลว่าใครเข้าเครื่องนี้ได้ ก็ยึดระบบได้ **เครื่องนี้จึงต้องล็อกหน้าจอและอยู่ในที่ที่คนทั่วไปเข้าไม่ถึง**

## ไฟฟ้าและ UPS

เซิร์ฟเวอร์ต่อ UPS ไว้แล้ว แต่ **UPS ต้องต่อสายข้อมูล (USB) เข้าเครื่องด้วย** ไม่ใช่แค่เสียบปลั๊กไฟ ถ้าไม่ต่อสายข้อมูล เครื่องจะไม่รู้ว่าไฟดับ พอแบต UPS หมดก็ดับกลางคันอยู่ดี ซึ่งเป็นสิ่งที่ UPS มีไว้ป้องกัน

ตรวจว่าต่อสายแล้วหรือยัง รันใน PowerShell

```
Get-CimInstance Win32_Battery
```

- **ได้ข้อมูลกลับมา** = เครื่องเห็น UPS แล้ว ใช้ได้
- **ไม่ได้อะไรเลย** = ยังไม่ได้ต่อสายข้อมูล หรือ UPS รุ่นนั้นไม่มีพอร์ตข้อมูล

ตั้งค่าไว้แล้วว่าเมื่อแบตเหลือ 10% ให้**ปิดเครื่องเอง** และเตือนที่ 25% ค่านี้จะเริ่มทำงานทันทีที่เครื่องเห็น UPS ไม่ต้องตั้งใหม่

UPS รุ่นถูกบางรุ่นไม่มีพอร์ตข้อมูล ถ้าเป็นรุ่นนั้นควรเปลี่ยนเป็นรุ่นที่มี เพราะเซิร์ฟเวอร์ที่ไม่มีคนเฝ้าตอนกลางคืน UPS ที่บอกเครื่องไม่ได้ ช่วยได้ครึ่งเดียว

## คำสั่งที่ใช้บ่อย

รันใน PowerShell ที่โฟลเดอร์ `F:\EX\sichomphu-remote`

```
npm run service:restart      เริ่มบริการใหม่
npm run service:stop         หยุดบริการ
npm run check:config         ตรวจไฟล์ตั้งค่า อ่านอย่างเดียว ไม่แก้อะไร
npm run check:hospital       ตรวจว่าหน้าเว็บเสิร์ฟได้จริง
npm run test:hospital        รันเทสต์ทั้งหมด
npm run build:hospital       สร้างหน้าเว็บภาษาไทยใหม่ หลังแก้เทมเพลต
npm run build:setup-exe      สร้างตัวติดตั้งสำหรับเครื่องลูกใหม่
npm run backup:copy -- H:\SCP-Remote-Backups    ก๊อปไฟล์สำรองไปอีกไดรฟ์
npm run allow:subnet         เพิ่มวง LAN ที่อนุญาต
```

## สิ่งที่ห้ามทำ

- **ห้ามลบหรือย้าย `.local\scp-remote`** ใบรับรองอยู่ในนั้น ถ้าหายโดยไม่มีไฟล์สำรอง ต้องเดินไปติดตั้งเอเจนต์ใหม่ทุกเครื่องในโรงพยาบาล
- **ห้ามเปิดพอร์ต 8443 ออกอินเทอร์เน็ต** ระบบนี้ออกแบบมาให้ใช้ในวงภายในเท่านั้น ใบรับรองก็ยังเป็นใบที่เครื่องสร้างเอง
- **ห้ามเปลี่ยน IP ของเซิร์ฟเวอร์** โดยไม่อ่าน `MOVING-THE-SERVER.md` ก่อน
- **ห้ามแก้ไฟล์ของ MeshCentral โดยไม่ใส่คอมเมนต์ `SCP-Remote:` กำกับ** และไม่จดลง `UPSTREAM-CHANGES.md` มีเทสต์คอยจับอยู่ ถ้าไม่จดเทสต์จะแดง
- **ห้ามข้ามเทสต์ `hospital/tests/viewonly.test.js`** เทสต์นั้นคุมไว้ว่าการดูหน้าจอโดยไม่ต้องขออนุญาต ยังผูกอยู่กับการที่เอเจนต์บล็อกเมาส์และคีย์บอร์ด ถ้าแยกสองอย่างนี้ออกจากกัน ใครก็เข้าคุมเครื่องได้โดยไม่ต้องขอ

## เรื่องความเป็นส่วนตัวที่ต้องรู้

ระบบตั้งไว้ให้ **ดูภาพหน้าจอได้โดยไม่ต้องขออนุญาต** ส่วนการเข้าคุมเครื่อง ใช้หน้าต่างคำสั่ง และเปิดไฟล์ ยังต้องขออนุญาตทุกครั้ง ตอนนี้แถบเตือนบนจอเครื่องปลายทางถูกปิดไว้ เหลือเพียงการแจ้งเตือนตอนเริ่มดู

การดูหน้าจอเครื่องที่เจ้าหน้าที่ใช้อยู่เข้าข่ายการเก็บข้อมูลส่วนบุคคลตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล **ควรมีประกาศเป็นลายลักษณ์อักษรแจ้งเจ้าหน้าที่ไว้ว่าหน้าจอของเครื่องโรงพยาบาลอาจถูกดูเพื่อการดูแลระบบ** และเก็บประกาศนั้นไว้

ประกาศฉบับนี้เก็บอยู่ที่ **`[ กรอก: มี/ยังไม่มี · ถ้ามีอยู่ที่ไหน ]`**

เซิร์ฟเวอร์บันทึกทุกครั้งที่มีการเปิดดูหน้าจอไว้ในหน้า **เหตุการณ์** ว่าใครดูเครื่องใดเมื่อไร เก็บไว้เป็นหลักฐานได้

## ถ้าจะเลิกใช้ระบบ

1. ถอนเอเจนต์ออกจากเครื่องลูกทุกเครื่องก่อน — สั่งจากหน้าเว็บได้ หรือรันบนเครื่องนั้น `"C:\Program Files\SCP-Remote\scpremote.exe" -fulluninstall` (เครื่องที่ลงก่อนเปลี่ยนชื่อจะอยู่ที่ `"C:\Program Files\Mesh Agent\MeshAgent.exe"`)
2. ตรวจว่าไม่เหลือเครื่องออนไลน์ในระบบแล้ว
3. `npm run service:uninstall`
4. ลบกฎไฟร์วอลล์ `SCP-Remote (TCP 8443)`
5. เก็บไฟล์สำรองชุดสุดท้ายไว้ตามระเบียบของโรงพยาบาลก่อนลบข้อมูล

**อย่าปิดเซิร์ฟเวอร์ทิ้งเฉย ๆ โดยไม่ถอนเอเจนต์** เอเจนต์จะค้างอยู่บนเครื่องลูกและพยายามต่อหาเซิร์ฟเวอร์ที่ไม่มีอยู่แล้วตลอดไป
