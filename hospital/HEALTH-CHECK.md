# ตรวจสุขภาพ & แก้ปัญหา (SCPclear บนแดชบอร์ด)

ต่อยอดจากโปรแกรม SCPclear ที่ใช้ที่หน้าเครื่อง ให้ตรวจและแก้ปัญหาได้จากแดชบอร์ดหรือมือถือ ทีละเครื่องหรือทุกเครื่องพร้อมกัน

## ใช้ที่ไหน

- **หน้าต่างรายละเอียดเครื่อง** (กดเครื่องบนแผนที่หรือในรายการ) → ส่วน "🩺 ตรวจสุขภาพ & แก้ปัญหา" → **ตรวจตอนนี้**
- **แถบเครื่องมือแดชบอร์ด** → **🩺 ตรวจสุขภาพทุกเครื่อง** (เรียงเครื่องที่มีปัญหามากสุดขึ้นก่อน กดชื่อเพื่อเปิดรายละเอียด) และ **🔤 ติดตั้งฟอนต์ไทย**

## การตรวจ (อ่านอย่างเดียว ไม่เปลี่ยนแปลงอะไร ใช้เวลาประมาณ 15 วินาที)

| หมวด | สิ่งที่ตรวจ |
|---|---|
| **ค้าง / ช้า** (ขึ้นเป็นเรื่องแรก) | โปรแกรมค้าง Not Responding ≥5 ครั้ง/7 วัน (บอกชื่อโปรแกรม), โปรแกรมเด้งปิดเอง ≥5 ครั้ง/7 วัน, Windows เตือนหน่วยความจำไม่พอ, แรมถูกใช้ ≥90%, เปิดเครื่องนานเกิน 2 นาที — พร้อมคำแนะนำ (เพิ่มแรม/เปลี่ยน SSD/โปรแกรมที่กินแรม/รีสตาร์ท) และขึ้นหัวข้อ 🐢 แรกในสรุปตรวจเช้า เครื่องที่ขึ้น Windows 11 ไม่ไหวใช้ Windows 10 ต่อได้ ระบบดูแค่ว่ายังใช้งานลื่นไหม |
| ระบบ | เปิดต่อเนื่องกี่วัน (เกิน 7 วันเหลือง เกิน 14 วันแดง), อัปเดตรอรีสตาร์ท, อัปเดตล่าสุด, ดับ/ค้างผิดปกติใน 14 วัน, Error ในระบบ 24 ชม., บริการหลักที่หยุด |
| ฮาร์ดแวร์ | RAM/CPU ที่ใช้อยู่, พื้นที่ไดรฟ์ C:, สุขภาพดิสก์/SMART, HDD หรือ SSD, อุปกรณ์ที่มีปัญหา |
| เครือข่าย | การ์ดแลน, IP (จับ 169.254 = DHCP ไม่ตอบ), Gateway, DNS, อินเทอร์เน็ต |
| เครื่องพิมพ์ | Print Spooler, งานพิมพ์ค้าง (นานกี่นาที), สถานะแต่ละเครื่อง (Offline / กระดาษติด / หมึกใกล้หมด / Paused), SCPPrint เปิดอยู่ไหม |
| ความเร็ว | โปรแกรมเปิดพร้อมเครื่อง, ไฟล์ชั่วคราว, โหมดพลังงาน, SSD |
| ฟอนต์ | ฟอนต์ไทยที่ยังไม่มี, TH Sarabun |
| การติดตั้ง Windows | **บันทึกไว้เป็นข้อมูล (สีเทา) ไม่นับเป็นปัญหา** — Windows ทุกแบบถือว่าใช้ได้ตามนโยบาย รพ.: ลงแบบข้ามเกณฑ์ (LabConfig Bypass*, AllowUpgradesWithUnsupportedTPMOrCPU, ไฟล์ unattend), ฉบับดัดแปลง (tiny11/Lite/TeamOS ฯลฯ, Defender หรือ Windows Update ถูกถอด), ปิด Windows Update, ไม่มี Edge — ไว้ใช้ตอนวางเรื่อง security |

พร้อมรายการโปรแกรมที่ใช้แรมมากสุด 6 อันดับ

## ปุ่มแก้ (ถามยืนยันทุกครั้ง บันทึกชื่อผู้สั่งในประวัติเครื่อง)

- **แก้ปริ้นไม่ออก**: หยุด Spooler → ลบงานพิมพ์ที่ค้างในคิว → เปิด Spooler ใหม่ แล้วรายงานจำนวนงานก่อน/หลัง ถ้าเครื่องนั้นแชร์เครื่องพิมพ์ (SCPPrint หรือ Shared) จะเตือนก่อนว่างานของเครื่องอื่นจะถูกล้างด้วย
- รีสตาร์ท Print Spooler · พิมพ์หน้าทดสอบ (ไม่แสดงกับเครื่องพิมพ์เสมือนเช่น PDF) · สั่งเครื่องพิมพ์ที่ Paused ให้ทำงานต่อ
- ล้าง DNS · เปิดบริการหลักที่หยุด (เฉพาะรายชื่อที่กำหนด: Spooler, Dnscache, Dhcp, LanmanWorkstation, LanmanServer, BITS, EventLog, W32Time, AudioSrv, Winmgmt)
- TRIM SSD (ปลอดภัย ไม่ลบไฟล์)
- เปิด/ปิดโปรแกรมเปิดพร้อมเครื่อง — สวิตช์เดียวกับ Task Manager โปรแกรมไม่ถูกลบ เปิดกลับได้ทันที (อย่าปิด HOSxP โปรแกรมอ่านบัตร และแอนตี้ไวรัส)
- ล้างไฟล์ชั่วคราว — ใช้ปุ่มเดิมของระบบ (ลบเฉพาะไฟล์เก่ากว่า 7 วัน ดู `TEMP-CLEANUP.md`)
- ติดตั้งฟอนต์ไทย

หลังแก้ ระบบจะตรวจซ้ำให้อัตโนมัติ

### ที่ตั้งใจไม่ใส่ (ยังใช้ SCPclear ที่หน้าเครื่องได้)

รีเซ็ตเครือข่าย (เน็ตหลุดจนรีสตาร์ท รีโมตกลับเข้าไม่ได้), รีเซ็ต Windows Update, ล้างถังขยะ (ลบไฟล์ผู้ใช้ถาวร), ลบแอป/AI/Bloatware และการปรับแต่ง Windows ทั้งเครื่อง

## ฟอนต์ไทย

อยู่ที่ `public/fonts/thai/` (สำเนาต้นฉบับที่ `F:\SCP-addons\fonts`) รวม **77 ไฟล์**:

- **ฟอนต์ราชการ/แห่งชาติ** (จาก `H:\ไฟล์คอม\fontthai`, ไฟล์ขึ้นต้น `SIPA-`): TH Sarabun New, TH SarabunIT๙, TH SarabunPSK, TH Niramit AS / IT๙ และฟอนต์แห่งชาติ 13 แบบของ SIPA — ใช้และแจกจ่ายได้ฟรี
- **Google Fonts** (SIL Open Font License): Sarabun 7 แบบ, Kanit 4, Prompt 4, IBM Plex Sans Thai 3, Noto Sans Thai 1

ไฟล์สัญญาและที่มาอยู่ใน `licenses/`

เครื่องลูกดาวน์โหลดจากเซิร์ฟเวอร์นี้ ตรวจ SHA-256 ตาม `manifest.json` ก่อนคัดลอกเข้า `C:\Windows\Fonts` ถ้าไฟล์ไม่ตรงจะไม่ติดตั้ง ตัวที่มีอยู่แล้วจะข้าม โปรแกรมที่เปิดอยู่ต้องปิดเปิดใหม่จึงจะเห็นฟอนต์ ถ้าเข้าเว็บด้วย IP ที่ใบรับรองไม่ตรง เครื่องลูกจะยอมรับใบรับรองนั้นเฉพาะการโหลดฟอนต์ เพราะความถูกต้องของไฟล์ยืนยันด้วย SHA-256 อยู่แล้ว

**เพิ่มฟอนต์เอง**: วางไฟล์ .ttf (ชื่อไฟล์ภาษาอังกฤษ) ใน `public/fonts/thai/` แล้วเพิ่มใน `manifest.json` (ชื่อไฟล์, SHA-256, ชื่อในรีจิสทรีแบบ `TH Sarabun New (TrueType)` เป็นตัวอักษรอังกฤษ เพราะคำสั่งส่งผ่าน PowerShell ทางอินพุตมาตรฐาน)

## โปรแกรม รพ.

- **PACS (Synapse)**: ตรวจว่าไฟล์ hosts มีชื่อ `syn5scph` (192.168.30.83) หรือยัง — แสดงเป็นสีเทา ไม่นับเป็นปัญหา เพราะไม่ใช่ทุกเครื่องต้องดูภาพเอกซเรย์ ปุ่ม **เพิ่ม** ทำแบบเดียวกับ `H:\ไฟล์คอม\worklist_Addhost.bat` แต่กดซ้ำไม่เพิ่มบรรทัดซ้ำ

## ข้อมูลที่เก็บ

- `scphealth/<เครื่อง>` ผลตรวจล่าสุด (แสดงได้แม้เครื่องปิด)
- `scphealthlog/<เครื่อง>` ปุ่มแก้ 30 ครั้งล่าสุด: ใคร ทำอะไร ผลอย่างไร (แสดงในประวัติเครื่อง 🩺)

ทั้งสองต้องรีสตาร์ทเซิร์ฟเวอร์หนึ่งครั้งหลังอัปเดต ก่อนหน้านั้นการตรวจและปุ่มแก้ใช้งานได้ แต่ผลอยู่เฉพาะหน้าเว็บที่เปิดอยู่

คำสั่งทั้งหมดส่งผ่าน Run Commands ของ MeshCentral ต้องมีสิทธิ์นี้บนเครื่องนั้น โค้ดอยู่ที่ `public/scripts/scp-health.js` ทดสอบที่ `hospital/tests/health.test.js`

## ตรวจเช้าอัตโนมัติ (เซิร์ฟเวอร์ทำเอง)

ทุกวันเวลา **07:30** เซิร์ฟเวอร์ตรวจสุขภาพทุกเครื่อง Windows ที่เปิดอยู่เอง (อ่านอย่างเดียว ไม่แก้อะไร) โดยใช้สคริปต์ตรวจตัวเดียวกับแดชบอร์ด ถ้าเซิร์ฟเวอร์เพิ่งเปิดตอนสาย จะตรวจให้ภายใน 3 ชั่วโมงหลังเวลาที่ตั้ง

- เก็บผลล่าสุดของแต่ละเครื่อง + ประวัติตัวเลขสำคัญ (ที่ว่างดิสก์ แรม ดับ/ค้าง งานพิมพ์ ไฟล์ชั่วคราว) ย้อนหลัง ~120 วัน
- ทำสรุป: ตรวจกี่เครื่อง ปกติกี่เครื่อง และเครื่องที่มีปัญหาสีแดงพร้อมเรื่องที่เจอ — ดูได้ที่ปุ่ม **🩺 ตรวจสุขภาพทุกเครื่อง**
- ผู้ดูแลระบบกด **สั่งตรวจเช้าตอนนี้** ในหน้าต่างเดียวกันได้ ไม่ต้องรอพรุ่งนี้

### ตั้งค่า (`.local/scp-remote/config.json` ใน `settings` แล้วรีสตาร์ท)

```json
"scpMorningCheck": "07:30",
"scpTelegram": { "token": "123456:ABC...", "chat": "-100123456789" },
"scpAlertWebhook": "https://ปลายทาง/hook"
```

- `scpMorningCheck`: เวลาตรวจ หรือ `"off"` เพื่อปิด
- `scpTelegram`: ส่งสรุปเข้า Telegram (สร้างบอทกับ @BotFather แล้วเพิ่มบอทเข้ากลุ่ม IT)
- `scpAlertWebhook`: ส่ง JSON `{ type: "morning", message, problems: [{ computer, issues }] }` ไปปลายทางใดก็ได้ (LINE OA ผ่านตัวกลาง, Discord ฯลฯ) — ตัวเดียวกับแจ้งเตือนเครื่องหลุด
- ถ้ายังไม่ตั้งทั้งสองอย่าง สรุปจะอยู่ในเซิร์ฟเวอร์เท่านั้น ไม่มีข้อมูลเครื่องออกนอกโรงพยาบาล

## แนวโน้ม

ในหน้าต่างรายละเอียดเครื่อง (ส่วนตรวจสุขภาพ) แสดงกราฟเล็ก: ที่ว่างไดรฟ์ C: (พร้อมคาดว่าจะเต็มในอีกกี่วันถ้าลดลงเกิน 50 MB/วัน), จำนวนดับ/ค้างผิดปกติ (ถ้าเพิ่มขึ้นให้ตรวจ UPS/ไฟ) และแรมที่ใช้ — ต้องมีผลตรวจเช้าอย่างน้อย 5 วัน

## เครื่องพิมพ์ทั้งโรงพยาบาล

ปุ่ม **🖨️ เครื่องพิมพ์ทั้ง รพ.** รวมเครื่องพิมพ์จริงทุกเครื่องจากผลตรวจล่าสุดของแต่ละคอม (ไม่รวม PDF/OneNote/Fax) กรองได้: มีปัญหา / หมึกใกล้หมด / ทั้งหมด พร้อมงานพิมพ์ค้างและ SCPPrint ที่ไม่ได้เปิด กด **แก้ปริ้นไม่ออก** หรือ **ดูเครื่อง** ได้จากรายการ

## มือถือ (/m)

การ์ดเครื่องที่เปิดอยู่มีปุ่ม **🖨️ แก้ปริ้นไม่ออก** ใต้ "ขอรีโมต" — ล้างงานค้าง + รีสตาร์ท Spooler ได้โดยไม่ต้องเปิดหน้าจอรีโมต เซิร์ฟเวอร์ตรวจสิทธิ์ Run Commands ของบัญชีนั้นบนเครื่องนั้นก่อนทุกครั้ง และบันทึกในประวัติเครื่อง (ระบุว่าสั่งจากมือถือ)
