# ตรวจสุขภาพ & แก้ปัญหา (SCPclear บนแดชบอร์ด)

ต่อยอดจากโปรแกรม SCPclear ที่ใช้ที่หน้าเครื่อง ให้ตรวจและแก้ปัญหาได้จากแดชบอร์ดหรือมือถือ ทีละเครื่องหรือทุกเครื่องพร้อมกัน

## ใช้ที่ไหน

- **หน้าต่างรายละเอียดเครื่อง** (กดเครื่องบนแผนที่หรือในรายการ) → ส่วน "🩺 ตรวจสุขภาพ & แก้ปัญหา" → **ตรวจตอนนี้**
- **แถบเครื่องมือแดชบอร์ด** → **🩺 ตรวจสุขภาพทุกเครื่อง** (เรียงเครื่องที่มีปัญหามากสุดขึ้นก่อน กดชื่อเพื่อเปิดรายละเอียด) และ **🔤 ติดตั้งฟอนต์ไทย**

## การตรวจ (อ่านอย่างเดียว ไม่เปลี่ยนแปลงอะไร ใช้เวลาประมาณ 15 วินาที)

| หมวด | สิ่งที่ตรวจ |
|---|---|
| ระบบ | เปิดต่อเนื่องกี่วัน (เกิน 7 วันเหลือง เกิน 14 วันแดง), อัปเดตรอรีสตาร์ท, อัปเดตล่าสุด, ดับ/ค้างผิดปกติใน 14 วัน, Error ในระบบ 24 ชม., บริการหลักที่หยุด |
| ฮาร์ดแวร์ | RAM/CPU ที่ใช้อยู่, พื้นที่ไดรฟ์ C:, สุขภาพดิสก์/SMART, HDD หรือ SSD, อุปกรณ์ที่มีปัญหา |
| เครือข่าย | การ์ดแลน, IP (จับ 169.254 = DHCP ไม่ตอบ), Gateway, DNS, อินเทอร์เน็ต |
| เครื่องพิมพ์ | Print Spooler, งานพิมพ์ค้าง (นานกี่นาที), สถานะแต่ละเครื่อง (Offline / กระดาษติด / หมึกใกล้หมด / Paused), SCPPrint เปิดอยู่ไหม |
| ความเร็ว | โปรแกรมเปิดพร้อมเครื่อง, ไฟล์ชั่วคราว, โหมดพลังงาน, SSD |
| ฟอนต์ | ฟอนต์ไทยที่ยังไม่มี, TH Sarabun |

พร้อมรายการโปรแกรมที่ใช้แรมมากสุด 6 อันดับ

## ปุ่มแก้ (ถามยืนยันทุกครั้ง บันทึกชื่อผู้สั่งในประวัติเครื่อง)

- **แก้ปริ้นไม่ออก**: หยุด Spooler → ลบงานพิมพ์ที่ค้างในคิว → เปิด Spooler ใหม่ แล้วรายงานจำนวนงานก่อน/หลัง ถ้าเครื่องนั้นแชร์เครื่องพิมพ์ (SCPPrint หรือ Shared) จะเตือนก่อนว่างานของเครื่องอื่นจะถูกล้างด้วย
- รีสตาร์ท Print Spooler · พิมพ์หน้าทดสอบ (ไม่แสดงกับเครื่องพิมพ์เสมือนเช่น PDF) · สั่งเครื่องพิมพ์ที่ Paused ให้ทำงานต่อ
- ล้าง DNS · เปิดบริการหลักที่หยุด (เฉพาะรายชื่อที่กำหนด: Spooler, Dnscache, Dhcp, LanmanWorkstation, LanmanServer, BITS, EventLog, W32Time, AudioSrv, Winmgmt)
- TRIM SSD (ปลอดภัย ไม่ลบไฟล์)
- เปิด/ปิดโปรแกรมเปิดพร้อมเครื่อง — สวิตช์เดียวกับ Task Manager โปรแกรมไม่ถูกลบ เปิดกลับได้ทันที (อย่าปิด HOSxP โปรแกรมอ่านบัตร และแอนตี้ไวรัส)
- ล้างไฟล์ชั่วคราว — ใช้ปุ่มเดิมของระบบ (ลบเฉพาะไฟล์เก่ากว่า 7 วัน ดู `TEMP-CLEANUP.md`)
- ติดตั้งฟอนต์ไทย

หลังแก้ ระบบจะตรวจซ้ำให้อัตโนมัติ

### ที่ตั้งใจไม่ใส่ (ยังใช้ SCPclear ที่หน้าเครื่องได้)

รีเซ็ตเครือข่าย (เน็ตหลุดจนรีสตาร์ท รีโมตกลับเข้าไม่ได้), รีเซ็ต Windows Update, ล้างถังขยะ (ลบไฟล์ผู้ใช้ถาวร), ลบแอป/AI/Bloatware และการปรับแต่ง Windows ทั้งเครื่อง

## ฟอนต์ไทย

อยู่ที่ `public/fonts/thai/` (สำเนาต้นฉบับที่ `F:\SCP-addons\fonts`) — Sarabun 7 แบบ, Kanit 4, Prompt 4, IBM Plex Sans Thai 3, Noto Sans Thai 1 รวม 19 ไฟล์ จาก Google Fonts ใช้ฟรีภายใต้ SIL Open Font License (ไฟล์สัญญาอยู่ใน `licenses/`)

เครื่องลูกดาวน์โหลดจากเซิร์ฟเวอร์นี้ ตรวจ SHA-256 ตาม `manifest.json` ก่อนคัดลอกเข้า `C:\Windows\Fonts` ถ้าไฟล์ไม่ตรงจะไม่ติดตั้ง ตัวที่มีอยู่แล้วจะข้าม โปรแกรมที่เปิดอยู่ต้องปิดเปิดใหม่จึงจะเห็นฟอนต์ ถ้าเข้าเว็บด้วย IP ที่ใบรับรองไม่ตรง เครื่องลูกจะยอมรับใบรับรองนั้นเฉพาะการโหลดฟอนต์ เพราะความถูกต้องของไฟล์ยืนยันด้วย SHA-256 อยู่แล้ว

**เพิ่มฟอนต์เอง** (เช่น TH Sarabun New / TH SarabunIT๙ ที่ใช้ในหนังสือราชการ): วางไฟล์ .ttf ใน `public/fonts/thai/` แล้วสร้าง `manifest.json` ใหม่ (ชื่อ, SHA-256, ชื่อในรีจิสทรีแบบ `TH Sarabun New (TrueType)`)

## ข้อมูลที่เก็บ

- `scphealth/<เครื่อง>` ผลตรวจล่าสุด (แสดงได้แม้เครื่องปิด)
- `scphealthlog/<เครื่อง>` ปุ่มแก้ 30 ครั้งล่าสุด: ใคร ทำอะไร ผลอย่างไร (แสดงในประวัติเครื่อง 🩺)

ทั้งสองต้องรีสตาร์ทเซิร์ฟเวอร์หนึ่งครั้งหลังอัปเดต ก่อนหน้านั้นการตรวจและปุ่มแก้ใช้งานได้ แต่ผลอยู่เฉพาะหน้าเว็บที่เปิดอยู่

คำสั่งทั้งหมดส่งผ่าน Run Commands ของ MeshCentral ต้องมีสิทธิ์นี้บนเครื่องนั้น โค้ดอยู่ที่ `public/scripts/scp-health.js` ทดสอบที่ `hospital/tests/health.test.js`
