# เครื่องมือช่าง SCPclear บนแดชบอร์ด

ยกเครื่องมือฝั่งช่างของ SCPclear 2.3 (โปรแกรมดูแลเครื่องของงาน IT) มาใช้ผ่าน SCP-Remote ได้ทั้งแบบทีละเครื่องและทั้งโรงพยาบาล โดยไม่ต้องไปนั่งหน้าเครื่อง ส่วนที่ซ้ำกับ [ตรวจสุขภาพ & แก้ปัญหา](HEALTH-CHECK.md) (ดิสก์/SMART, ไฟล์ชั่วคราว, โปรแกรมเปิดพร้อมเครื่อง, เครื่องพิมพ์, ไลเซนส์) ไม่ได้ทำซ้ำ

## ใช้ที่ไหน

- **แถบเครื่องมือแดชบอร์ด** → กลุ่ม 🧰 ดูแลเครื่อง → **🛠️ เครื่องมือช่าง SCPclear** (หน้ารวมทั้ง รพ. มี 6 แท็บ)
- **หน้าต่างรายละเอียดเครื่อง** → ส่วน "🧰 เครื่องมือช่าง (SCPclear)" ใต้ส่วนตรวจสุขภาพ

## สิ่งที่ทำได้

| ปุ่ม | ทำอะไร | เปลี่ยนเครื่องไหม | เวลา |
|---|---|---|---|
| 🔍 BSOD / RAM / แบตเตอรี่ | อ่านไฟล์ `C:\Windows\Minidump` เองเพื่อบอก**ไดรเวอร์ตัวที่ทำจอฟ้า** + รหัส stop code พร้อมความหมายภาษาไทยและวิธีแก้ (180 วันล่าสุด) · นับครั้งที่ไฟดับ/ปิดกะทันหัน (Kernel-Power 41 รหัส 0) แยกจากจอฟ้า · ช่อง RAM ที่ใช้/ว่าง ชนิด DDR/DIMM/SO-DIMM ความเร็ว และที่บอร์ดรับได้สูงสุด → คำแนะนำซื้อ RAM · แบตโน้ตบุ๊ก: ความจุตอนนี้เทียบตอนใหม่ (%) และจำนวนรอบ | ไม่ (อ่านอย่างเดียว) | ~5 วินาที |
| 🛡️ ตรวจไฟล์ Windows (SFC) | `sfc /verifyonly` ตรวจอย่างเดียว ไม่ซ่อม | ไม่ | 5–20 นาที (ถามก่อน) |
| 🧩 DISM CheckHealth | `DISM /Online /Cleanup-Image /CheckHealth` | ไม่ | ไม่ถึงนาที |
| ⚡ วัดความเร็วดิสก์ | เขียน/อ่านไฟล์ชั่วคราว 256 MB แบบไม่ผ่านแคช + สุ่มอ่าน 4K 5 วินาที แล้วลบทิ้ง | ไฟล์ชั่วคราวใน `C:\Windows\Temp` (ลบเอง) | ~30 วินาที (ถามก่อน) |
| 📡 สแกน LAN | จากเครื่องที่เลือก ping ทั้งวง /24 แล้วอ่านชื่อ MAC พอร์ตที่ใช้บ่อย บอกชนิด (เราเตอร์ / เครื่องพิมพ์ / กล้อง-NVR / Windows / อุปกรณ์มีหน้าเว็บ) และบอกว่าเครื่องไหนมี SCP-Remote แล้ว ใส่วงเองได้ เช่น `192.168.2` | ไม่ | ~1 นาที |
| 🩹 ซ่อม Windows Update | มีการ์ดความคืบหน้า 0–100% 6 ขั้น: ตรวจพื้นที่ดิสก์ (ต้องเหลือ ≥ 8 GB) และการตั้งค่า → เปิดบริการอัปเดตที่หยุดอยู่ → พักบริการ → **ล้างเฉพาะแคชที่โหลดค้าง** (`SoftwareDistribution\Download` Windows โหลดใหม่เอง) → DISM CheckHealth (อ่านอย่างเดียว) → ถาม Windows Update ว่ามีอะไรรออยู่ (ชื่อ KB) บอกด้วยว่ามีรีสตาร์ทรออยู่ไหม **ไม่ติดตั้งอัปเดตและไม่รีสตาร์ทเครื่อง** ถ้าเครื่องปิด Windows Update ไว้ (นโยบาย `NoAutoUpdate` หรือบริการ Disabled) จะไม่แตะต้อง บอกให้ตัดสินใจที่หน้าเครื่อง ถ้าค้นหาอัปเดตเกิน 6 นาทีแสดงว่าเครื่องออก Windows Update ไม่ได้ (ตรวจอินเทอร์เน็ต/พร็อกซี) ไม่แตะ `catroot2`/`DataStore` (ประวัติอัปเดต) | ล้างแคชอัปเดต + เปิด/พักบริการ (ถามก่อน) | 2–8 นาที |
| ⬇️ ติดตั้งอัปเดต | มีการ์ดความคืบหน้า 5 ขั้น (ตรวจพื้นที่/นโยบาย → ค้นหา → ดาวน์โหลด → ติดตั้ง → ตรวจผล) ติดตั้งอัปเดตความปลอดภัย/คุณภาพ**ไม่เกิน 10 รายการต่อครั้ง** ผ่านบริการ Windows Update ของระบบเอง (COM `Microsoft.Update.Session`) **ข้ามโดยตั้งใจ:** อัปเดตเปลี่ยนเวอร์ชัน Windows (feature update / Upgrade to Windows), ไดรเวอร์ (ใช้คลังไดรเวอร์แทน) และอัปเดตที่ต้องให้ผู้ใช้กด **ไม่รีสตาร์ทเครื่องให้เอง** บอกว่าต้องรีสตาร์ทไหม ผลบอกรายการที่สำเร็จ/ไม่สำเร็จ/ที่ข้าม ถ้าเครื่องปิด Windows Update ไว้ตั้งใจ หรือที่ว่างไม่ถึง 8 GB จะไม่เริ่ม ถ้าเกิน 25 นาที หน้าเว็บหยุดรอ (Windows อาจยังติดตั้งต่อ ให้ดูที่หน้าเครื่อง) | ติดตั้งอัปเดต (ถามก่อน) | 5–25 นาที |
| 🔄 รีสตาร์ท (แจ้งผู้ใช้ 5 นาที) / ✋ ยกเลิกรีสตาร์ท | `shutdown /r /t 300` พร้อมข้อความภาษาไทยบนจอผู้ใช้ ให้เวลาบันทึกงาน 5 นาที ยกเลิกได้ด้วยปุ่มยกเลิก (`shutdown /a`) ไม่มีโหมดรีสตาร์ททันทีหรือบังคับปิดโปรแกรม | รีสตาร์ทเครื่อง (ถามก่อน) | 5 นาที |
| 📦 ลงโปรแกรม | winget แบบเงียบให้ทุกผู้ใช้ เลือกจากรายการที่ใช้ใน รพ. หรือพิมพ์ winget id เอง ติดตั้งพร้อมกันหลายเครื่องได้ (ครั้งละไม่เกิน 6 โปรแกรม) | ติดตั้งโปรแกรม (ถามก่อน) | แล้วแต่โปรแกรม |
| 🧹 ส่ง SCPclear | ให้เครื่องดาวน์โหลด SCPclear.exe จากเซิร์ฟเวอร์ ตรวจ SHA-256 แล้ววางที่ `C:\ProgramData\SCPclear` + ทางลัดบนเดสก์ท็อปทุกผู้ใช้ ไม่เปิดโปรแกรมเอง | วางไฟล์ + ทางลัด (ถามก่อน) | ไม่ถึงนาที |

หน้ารวมทั้ง รพ.: **💥 จอฟ้า** สรุปว่าไดรเวอร์ตัวไหนทำให้เครื่องล่มมากที่สุดกี่เครื่อง · **🧠 อัปเกรด RAM** เรียงเครื่อง RAM น้อยสุดก่อน พร้อมยอดที่ควรจัดซื้อ (เช่น DDR4 DIMM × 12) · **🔋 แบตโน้ตบุ๊ก** เรียงแบตเสื่อมมากสุดก่อน · **📦 ลงโปรแกรม** · **📡 สแกน LAN** (รวมรายการ **🧭 เครื่อง Windows ที่ยังไม่ได้ลง SCP-Remote** จากทุกการสแกน — ดูจากพอร์ต 445/3389 และเทียบกับ IP/ชื่อเครื่องในระบบ — พิมพ์เป็นใบติ๊กพร้อมช่องหน่วยงาน/หมายเหตุ หรือคัดลอก IP ไปเดินติดตั้งเอง) · **🧹 SCPclear** ส่งทุกเครื่องที่ออนไลน์

## ทำงานยังไง

- ทุกปุ่มส่ง `public/scripts/scp-tech.ps1` ผ่าน Run Commands ของ MeshCentral ในสิทธิ์ SYSTEM แบบเดียวกับตรวจสุขภาพ ต้องมีสิทธิ์ Run Commands กับเครื่องนั้น สคริปต์ตอบกลับบรรทัดเดียว `SCP_TECH:{json}`
- สคริปต์ห้ามมีบรรทัดว่างและต้องเป็น ASCII ล้วน (เอเจนต์ป้อนผ่าน stdin ของ PowerShell บรรทัดว่างจะตัดบล็อก) — `hospital/tests/tech.test.js` ตรวจไว้
- เครื่องหนึ่งทำได้ทีละคำสั่ง ถ้าเครื่องกำลังทำอย่างอื่นอยู่ (เช่นตรวจสุขภาพ) หน้าเว็บจะลองใหม่เองทุก 20 วินาที
- ผลของหน้ารวม (BSOD/RAM/แบต, SFC, DISM, ความเร็วดิสก์) เก็บไว้ใน**เบราว์เซอร์ที่ใช้** ไม่ได้เก็บบนเซิร์ฟเวอร์ (จะได้ไม่ต้องรีสตาร์ทเซิร์ฟเวอร์) เปิดจากเครื่องอื่นต้องกดอ่านใหม่
- winget ในสิทธิ์ SYSTEM: สคริปต์เรียก `winget.exe` จากโฟลเดอร์ `WindowsApps` ตรง ๆ ใช้ `--scope machine` ก่อน ถ้าโปรแกรมไม่มีแบบทั้งเครื่องจะลองแบบปกติ เครื่องที่ไม่มี App Installer จะขึ้นว่าไม่มี winget
- SFC/DISM ที่นี่ **ตรวจอย่างเดียว** ถ้าพบความเสียหาย ให้ซ่อมที่หน้าเครื่อง (SCPclear › เครื่องมือ Windows หรือ `sfc /scannow`, `DISM /RestoreHealth`) เพราะใช้เวลานานและเอเจนต์ตัดคำสั่งที่เกิน 30 นาที

## อัปเดต SCPclear บนเซิร์ฟเวอร์

ไฟล์อยู่ที่ `public/tools/SCPclear.exe` และ `public/tools/scpclear.json` (เวอร์ชัน ขนาด SHA-256) เมื่อ build SCPclear รุ่นใหม่แล้ว:

```
powershell -ExecutionPolicy Bypass -File scripts\update-scpclear.ps1 -Exe "C:\Users\Chairat_Pra\Desktop\SCPclear\SCP2\SCPclear.exe"
```

ไม่ต้องรีสตาร์ทเซิร์ฟเวอร์ เครื่องลูกดาวน์โหลดจากที่อยู่เซิร์ฟเวอร์ที่เอเจนต์ใช้อยู่ (อ่านจากไฟล์ `.msh`) ใบรับรองของเซิร์ฟเวอร์เป็นแบบ self-signed จึงไม่ตรวจใบรับรอง แต่ตรวจ SHA-256 ที่หน้าเว็บส่งไปแทน ไฟล์ที่ไม่ตรงจะถูกลบทิ้ง

หมายเหตุ: โฟลเดอร์ `public/` เปิดให้ดาวน์โหลดได้โดยไม่ต้องล็อกอิน (เครื่องลูกโหลดได้โดยไม่ต้องมีบัญชี) ใครอยู่ในเครือข่าย รพ. ก็โหลด SCPclear.exe ได้ ซึ่งตั้งใจไว้เพราะเป็นโปรแกรมของ รพ. เอง อย่าวางไฟล์ลับไว้ใน `public/tools`
