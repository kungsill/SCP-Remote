# ของที่แก้ในไฟล์ต้นฉบับ MeshCentral

ระบบนี้แก้ไฟล์ของ MeshCentral 1.2.5 โดยตรงในหลายจุด MeshCentral ออกแพตช์ความปลอดภัยเรื่อย ๆ วันที่จะอัปเกรด ไฟล์ใหม่จะทับของเราหมด เอกสารนี้คือรายการว่าต้องเอาอะไรกลับมาใส่บ้าง

## กติกาที่ทำให้เอกสารนี้ไม่ล้าสมัย

**ทุกครั้งที่แก้ไฟล์ต้นฉบับ ต้องเขียนคอมเมนต์ที่ขึ้นต้นว่า `SCP-Remote:` กำกับไว้เสมอ** พร้อมเหตุผล ไม่ใช่แค่บอกว่าทำอะไร

ไล่รายการปัจจุบันได้เองด้วยคำสั่งนี้ ถ้าผลไม่ตรงกับตารางข้างล่าง แปลว่าเอกสารนี้เก่าแล้ว

```
grep -rn "// SCP-Remote\|/\* SCP-Remote\|<!-- SCP-Remote" --include=*.js --include=*.handlebars \
  --exclude-dir=node_modules --exclude-dir=.local --exclude-dir=.git \
  --exclude-dir=hospital --exclude-dir=translations . | grep -v "/scp-"
```

## แบ่งตามความยากตอนอัปเกรด

### กลุ่ม ก — ไฟล์ของเราเอง ไม่ต้องทำอะไร

อัปเกรดแล้วก๊อปกลับมาวางได้เลย ไม่ชนกับใคร

`hospital/` ทั้งโฟลเดอร์ · `scripts/*hospital*.js`, `check-config.js`, `allow-subnet.js`, `build-setup-exe.js`, `copy-backups.js`, `service-*.js` · `public/scripts/scp-*.js` · `public/styles/scp-*.css` · `agents/modules_meshcore/scp-viewonly.js` · `agents/modules_meshcore/win-scp-userconsent.js` · `public/fonts/sarabun/` · `public/images/scp-logo.png`

**นี่คือส่วนใหญ่ของงานที่ทำไป และตั้งใจให้เป็นแบบนี้** ของใหม่ควรไปอยู่ในไฟล์ของตัวเองเสมอ ไม่แทรกในไฟล์ต้นฉบับถ้าเลี่ยงได้

## ขั้นตอนเวลาจะอัปเกรด MeshCentral

1. **อ่านบันทึกการเปลี่ยนแปลงของ MeshCentral ก่อน** ว่าเวอร์ชันใหม่แตะไฟล์ในกลุ่ม ค ตรงไหนบ้าง ถ้าเขาเขียนส่วนนั้นใหม่หมด การแก้ของเราอาจใช้ไม่ได้และต้องออกแบบใหม่
2. แตกเวอร์ชันใหม่ไว้คนละโฟลเดอร์ อย่าทับของเดิม
3. ก๊อปกลุ่ม ก ไปวาง
4. ไล่กลุ่ม ค ทีละแถวในตารางข้างบน ใส่คอมเมนต์ `SCP-Remote:` กำกับทุกจุดเหมือนเดิม
5. ทำกลุ่ม ข และ ง
6. `npm run build:hospital` แล้ว `npm run test:hospital` — เทสต์หลายตัวอ่านโค้ดจริงเพื่อยืนยันว่าการแก้ยังอยู่ โดยเฉพาะ `hospital/tests/viewonly.test.js` ที่ตรวจว่าการยกเว้นกล่องขออนุญาตยังผูกกับการบล็อกอินพุตอยู่
7. ทดสอบกับเครื่องทดสอบเครื่องเดียวก่อน โดยเฉพาะกล่องขออนุญาตและจอสตรีม
8. ค่อยเอาขึ้นของจริง

## ข้อควรรู้

จุดที่เสี่ยงที่สุดคือ **กลุ่ม ค แถวที่เกี่ยวกับ view-only ทั้งสามจุด** (`meshuser.js`, `agents/meshcore.js`, `agent-redir-ws`) ทั้งสามต้องอยู่ครบพร้อมกัน ถ้าเหลือแค่การยกเว้นกล่องขออนุญาตโดยไม่มีการบล็อกอินพุต จะกลายเป็นว่าใครก็เข้าคุมเครื่องได้โดยไม่ต้องขออนุญาต เทสต์ใน `hospital/tests/viewonly.test.js` มีไว้จับกรณีนี้โดยเฉพาะ **อย่าข้ามเทสต์นั้นเด็ดขาด**
