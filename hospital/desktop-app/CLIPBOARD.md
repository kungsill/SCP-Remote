# SCP-Remote 0.2.0 — คลิปบอร์ดข้อความและไฟล์สองทาง

ใช้กับโปรแกรม Windows SCP-Remote และเอเจนต์รุ่น **2026.09.21.1** ขึ้นไป เครื่องปลายทางต้องมีผู้ใช้ Windows ลงชื่อเข้าใช้อยู่ ตัวช่วยใช้ .NET Framework 4.x และทำงานในบัญชีผู้ใช้ที่กำลังรีโมต ไม่ใช่คลิปบอร์ดของบริการ SYSTEM

## วิธีใช้

1. เปิดโปรแกรมรุ่นใหม่ เลือกเครื่อง แล้วรอปลายทางอนุญาตรีโมตตามปกติ
2. **เครื่องเรา → เครื่องปลายทาง:** เลือกไฟล์/โฟลเดอร์ใน Explorer กด Ctrl+C คลิกตำแหน่งปลายทางในจอรีโมต แล้วกด Ctrl+V
3. **เครื่องปลายทาง → เครื่องเรา:** เลือกไฟล์/โฟลเดอร์ในจอรีโมต กด Ctrl+C รอข้อความ **100% พร้อมแล้ว** จากนั้นกลับมา Explorer บนเครื่องเราแล้วกด Ctrl+V
4. ครั้งแรกที่ใช้คลิปบอร์ดในแต่ละการเชื่อมต่อ ปลายทางจะมีคำขออนุญาตรับ–ส่งไฟล์เพิ่มเติม หากไม่อนุญาตจะไม่อ่านหรือเขียนคลิปบอร์ด

**ปุ่มวางไฟล์ด้วยเมาส์:** ที่มุมล่างซ้ายของหน้าต่างรีโมตมีปุ่ม **📋 วางไฟล์ลงเครื่องรีโมต** สำหรับคนที่อยากใช้เมาส์แทนคีย์บอร์ด — คัดลอกไฟล์ในเครื่องคุณก่อน (Ctrl+C หรือคลิกขวา Copy) แล้วกดปุ่มนี้ ทำงานเหมือน Ctrl+V ทุกอย่าง (ทิศเครื่องคุณ→รีโมตเท่านั้น) เมนูคลิกขวาของ Windows ปลายทางแทรกปุ่มเข้าไปไม่ได้ เพราะเป็นเมนูของ OS เครื่องนั้น

ข้อความใช้ปุ่มเดียวกัน รองรับภาษาไทยและอังกฤษ ขณะพิมพ์ในช่องข้อความหรือกล่องโต้ตอบของหน้าเว็บ ระบบจะไม่ดัก Ctrl+C / Ctrl+V

สถานะแสดง 4 ขั้นตอน: เตรียมและขออนุญาต → โอนพร้อมเปอร์เซ็นต์จากจำนวนไบต์จริง → ตรวจสอบ → พร้อมวาง สามารถยกเลิกระหว่างโอนได้ หากพื้นที่ไม่พอ ข้อมูลไม่ตรง หรือมีการคัดลอกข้อมูลใหม่ระหว่างรอ ระบบจะแจ้งข้อผิดพลาดและไม่แสดงว่าสำเร็จ

**100% พร้อมวาง** หมายถึงโอนเข้าพื้นที่พักและตั้งคลิปบอร์ดสำเร็จ ไม่ใช่การยืนยันว่า Explorer วางลงโฟลเดอร์สุดท้ายแล้ว Explorer ยังอาจถามชื่อซ้ำหรือสิทธิ์เขียนปลายทาง

## ขอบเขตและไฟล์พัก

- รองรับไฟล์หลายรายการ โฟลเดอร์ โฟลเดอร์ว่าง ไฟล์ขนาดศูนย์ และชื่อภาษาไทย
- เป็นการคัดลอกเท่านั้น ไม่รองรับการย้ายไฟล์ด้วย Ctrl+X
- ไฟล์ต้องโอนครบก่อนนำไปวางเครื่องอีกฝั่ง โดยเฉพาะไฟล์ใหญ่ ไม่ใช่การจองไฟล์เสมือนเพื่อดาวน์โหลดหลังวาง
- จำกัด 10 GB และ 10,000 รายการต่อครั้ง; ข้อจำกัดความยาวพาธของ Windows/.NET ยังมีผล ไม่ตาม junction/symlink
- ไฟล์ที่โอนสำเร็จพักที่ `%LOCALAPPDATA%\SCP-Remote\Clipboard\<รหัสงาน>` เพื่อให้วางซ้ำได้แม้ปิดหน้าต่างรีโมต ใช้พื้นที่ดิสก์ตามขนาดไฟล์ที่คัดลอก ไม่ได้ลบทันทีหลังโอน หลังวางเสร็จและไม่ต้องการวางซ้ำ สามารถลบโฟลเดอร์งานนั้นได้
- งานที่ยังโอนไม่ครบจะยกเลิกและพยายามล้างเฉพาะพื้นที่พักของงานนั้นเมื่อยกเลิกหรือปิดการเชื่อมต่อ ไฟล์ต้นฉบับไม่ถูกลบ
- ฟังก์ชันนี้อยู่ในโปรแกรม Windows; การเปิด SCP-Remote ในเว็บเบราว์เซอร์ทั่วไปยังใช้รับ–ส่งไฟล์/ลากไฟล์ตามเดิม

## การพัฒนาและผลทดสอบ

`npm run build:clipboard` คอมไพล์ `clipboard/ClipboardHost.cs` และสร้างโมดูล payload ของเอเจนต์ `npm run package` สร้างโปรแกรมพร้อมแยก helper ออกนอก app.asar เพื่อให้ Windows เรียกใช้งานได้

ตัวช่วยอ่าน CF_HDROP จริง ตรวจ SHA-256 ทุกชุดข้อมูลและอ่านข้อมูลที่เขียนกลับมาเทียบ ใช้ช่องไฟล์ที่ผ่านสิทธิ์และการอนุญาตเดิม ไม่เปิดพอร์ตเครือข่ายเพิ่ม IPC ของ Windows ใช้ named pipe ภายในเครื่อง ชื่อและรหัสไฟล์จาก renderer ไม่สามารถระบุพาธต้นทางอิสระได้

ทดสอบ helper บน Windows ด้วยไฟล์ที่สร้างขึ้นใหม่: 21 รายการผ่าน รวมข้อมูลภาษาไทย ไฟล์หลายชุด ข้อมูลผิดแฮช พาธไม่ปลอดภัย และคลิปบอร์ดเปลี่ยนระหว่างโอน ทดสอบ MeshAgent ตัวจริงบนเครื่องหลักผ่าน win-dispatcher และ named pipe ส่ง 300,123 ไบต์ใน 3 ชุด ตรวจสอบและยกเลิกงานสำเร็จ

**ยังต้องทดสอบการกดอนุญาตและ Ctrl+C/Ctrl+V ระหว่างสองเครื่องจริงที่ test01 เมื่อมีเจ้าหน้าที่อยู่หน้าเครื่อง** การทดสอบบนเครื่องหลักไม่ได้ทดแทนการตรวจรับขั้นตอนนี้
