1. ภาพรวม

SCP-Remote คือเว็บสำหรับฝ่ายไอทีใช้ดูแลคอมพิวเตอร์ทุกเครื่องในโรงพยาบาลจากหน้าจอเดียว: รีโมตเข้าเครื่อง ส่งไฟล์ ตรวจสุขภาพเครื่อง หาดิสก์ที่ใกล้เสีย ออกใบงานช่างพร้อมวิธีซ่อม ดูเครื่องพิมพ์ทั้ง รพ. วางแผนงบเปลี่ยนเครื่อง และใช้บนมือถือได้ พัฒนาต่อยอดจากโปรแกรมโอเพนซอร์ส MeshCentral 1.2.5 (สัญญาอนุญาต Apache-2.0) โดยเพิ่มหน้าภาษาไทยและงานเฉพาะโรงพยาบาล

ส่วนประกอบ

ส่วนอยู่ที่ไหนทำอะไร
เซิร์ฟเวอร์ SCP-Remoteเครื่อง Windows 1 เครื่องในวง LAN (โฟลเดอร์ server/)เว็บ https://<IP>:8443 เก็บรายชื่อเครื่อง ผู้ใช้ ประวัติ และสั่งงานเอเจนต์
เอเจนต์ (Mesh Agent)ทุกเครื่องลูก ทำงานเป็นบริการ Windows ชื่อ Mesh Agentต่อกลับมาหาเซิร์ฟเวอร์เอง ให้รีโมต ส่งไฟล์ รันคำสั่งตรวจ/แก้
ตัวติดตั้งเครื่องลูกserver/hospital/client-setup/ตัวช่วยติดตั้งเอเจนต์แบบกดถัดไป ตั้งชื่อเครื่อง เลขครุภัณฑ์ ปีงบ ราคา
SCPcleartools/SCPclear-plus/โปรแกรมทำความสะอาด/ปรับแต่งที่หน้าเครื่อง
SCPPrinttools/SCPPrint/แชร์เครื่องพิมพ์ผ่านพอร์ต 9100 ให้เครื่องอื่นพิมพ์ผ่าน

ทำงานยังไง (ภาพใหญ่)

เครื่องลูก + เอเจนต์→ ต่อออก wss://เซิร์ฟเวอร์:8443 →เซิร์ฟเวอร์ SCP-Remote← เปิดเว็บ ←ช่าง (คอม/มือถือ)
  • เอเจนต์เป็นฝ่ายต่อออกไปหาเซิร์ฟเวอร์ เครื่องลูกจึงไม่ต้องเปิดพอร์ตรับ
  • เอเจนต์จำลายนิ้วมือใบรับรองของเซิร์ฟเวอร์ไว้ จะคุยกับเซิร์ฟเวอร์ตัวจริงเท่านั้น เซิร์ฟเวอร์อื่นสั่งเครื่องไม่ได้
  • การตรวจสุขภาพคือการส่งสคริปต์ PowerShell แบบอ่านอย่างเดียวไปให้เอเจนต์รันแล้วส่งผลกลับ ปุ่มแก้ทุกปุ่มต้องกดยืนยันและบันทึกว่าใครสั่ง

2. ติดตั้งเซิร์ฟเวอร์

ต้องมี

  • เครื่อง Windows 10/11 หรือ Windows Server ที่เปิดตลอดเวลา IP คงที่ (ตั้งจองใน DHCP หรือกำหนดเอง) แรม 4 GB ขึ้นไป
  • Node.js 20 ขึ้นไป (ตัวติดตั้งจะช่วยลงให้ ทดสอบกับ 22.17)

วิธีที่ 1: คลิกเดียว (แนะนำ)

  1. เปิดโฟลเดอร์ 1-SCP-Remote-Suite ดับเบิลคลิก START-HERE.cmd กด Yes เมื่อ Windows ขอสิทธิ์
  2. ตัวติดตั้งจะ: ตรวจ/ลง Node.js → ลงแพ็กเกจ → สร้างหน้าเว็บภาษาไทย → สร้างทางลัดบนเดสก์ท็อป (SCP-Remote, SCPclear, ติดตั้ง SCPPrint) → ถามว่าจะให้เปิดเองทุกครั้งที่เปิดเครื่องไหม (บริการ Windows) → เปิดเบราว์เซอร์
  3. หน้าแรกให้สร้างบัญชีแรก บัญชีนี้เป็นผู้ดูแลระบบ เบราว์เซอร์จะเตือนเรื่องใบรับรอง เป็นปกติของใบรับรองที่สร้างเอง กด Advanced → Continue

วิธีที่ 2: ทีละคำสั่ง

cd 1-SCP-Remote-Suite\server
npm ci                     # ลงแพ็กเกจ
npm run build:hospital     # สร้างหน้าเว็บไทย/อังกฤษ
npm run start:hospital     # เปิดชั่วคราว (ปิดหน้าต่าง = ปิดระบบ)
npm run service:install    # หรือ ติดตั้งเป็นบริการ Windows (PowerShell แบบผู้ดูแล)

ครั้งแรกระบบจะคัดลอก hospital/config.example.json ไปเป็น .local/scp-remote/config.json และสร้างฐานข้อมูลกับใบรับรองใน .local/scp-remote/

โฟลเดอร์ .local/scp-remote คือหัวใจของระบบ มีฐานข้อมูล บัญชี และใบรับรองที่เครื่องลูกเชื่อถือ ถ้าหายโดยไม่มีไฟล์สำรอง ต้องเดินไปลงเอเจนต์ใหม่ทุกเครื่อง ห้ามลบหรือย้ายโดยไม่สำรอง

คำสั่งที่ใช้บ่อย (รันในโฟลเดอร์ server)

คำสั่งใช้เมื่อ

npm run update:systemอัปเดตทั้งระบบ: build หน้าเว็บ → รีสตาร์ต → ดันโค้ดใหม่ไปเครื่องลูก (ใส่ -- --check เพื่อดูเฉย ๆ)

3. เครือข่าย ความปลอดภัย และสำรองข้อมูล

วงเครือข่ายที่อนุญาต

เซิร์ฟเวอร์รับเฉพาะวง LAN ที่อนุญาต เพิ่มวงด้วย node scripts/allow-subnet.js add 192.168.10.0/24 แล้วรีสตาร์ต ตัวติดตั้งกฎไฟร์วอลล์ SCP-Remote (TCP 8443) จำกัดเฉพาะวงเหล่านี้ ถ้าโรงพยาบาลมีหลายวง (หลาย VLAN) ต้องให้ทุกวงวิ่งถึงเซิร์ฟเวอร์ที่พอร์ต 8443

ความปลอดภัยที่ต้องทำ

  • เปิดยืนยันตัวตน 2 ชั้น ให้บัญชีผู้ดูแล: บัญชีของฉัน → ความปลอดภัย → เพิ่มแอปยืนยันตัวตน
  • ห้ามเปิดพอร์ต 8443 ออกอินเทอร์เน็ตตรง ๆ ถ้าต้องรีโมตจากนอก รพ. ใช้ Cloudflare Tunnel หรือ Tailscale ตามคู่มือ REMOTE-OVER-INTERNET.md และ CLOUDFLARE-SETUP.md
  • เปลี่ยนรหัส admin เมื่อมีคนลาออก และดูหน้า เหตุการณ์ ทุกเดือน
  • การดูหน้าจอเครื่องที่มีคนใช้อยู่เกี่ยวกับข้อมูลส่วนบุคคล ควรมีประกาศแจ้งเจ้าหน้าที่ตามนโยบายของหน่วยงาน (การเข้าคุมเครื่องมีหน้าต่างขออนุญาตบนเครื่องลูก)

สำรองข้อมูล

ระบบสำรองอัตโนมัติทุกคืน (ไฟล์ meshcentral-autobackup-*.zip) และก๊อปสำเนาไปอีกไดรฟ์ได้ทุกวัน ตรวจทุกเดือนว่ามีไฟล์ของวันล่าสุดจริง ย้ายเซิร์ฟเวอร์ไปเครื่องใหม่: อ่าน MOVING-THE-SERVER.md ก่อน (ถ้า IP เซิร์ฟเวอร์เปลี่ยน เครื่องลูกจะหาไม่เจอ)

4. เอเจนต์

เอเจนต์คืออะไร

โปรแกรมเล็ก ๆ (Mesh Agent) ที่ลงในเครื่องลูกทุกเครื่อง ทำงานเป็นบริการ Windows ชื่อ Mesh Agent อยู่ใน C:\Program Files\Mesh Agent\ มีไฟล์สำคัญ:

ไฟล์คืออะไร
MeshAgent.exeตัวโปรแกรม
MeshAgent.mshที่อยู่เซิร์ฟเวอร์ + ลายนิ้วมือใบรับรอง + กลุ่มอุปกรณ์ที่สังกัด
MeshAgent.dbตัวตนของเครื่อง ถ้าเก็บไว้ ลงวินใหม่แล้วคืนไฟล์นี้ เครื่องจะกลับมาเป็นรายการเดิม
MeshAgent.tagชื่อเครื่องและคำอธิบายที่ตั้งตอนติดตั้ง

วิธีลงเอเจนต์ (3 แบบ)

แบบ ก: ตัวติดตั้งของ รพ. (แนะนำ)

  1. สร้างตัวติดตั้งครั้งเดียว: npm run build:setup-exe ได้ hospital/client-setup/SCP-Remote-Setup.exe (ฝังที่อยู่เซิร์ฟเวอร์ของคุณไว้ อย่าแจกนอกหน่วยงาน)
  2. ที่เครื่องลูก เปิด SCP-Remote-Setup.exe → อ่านคำขอความยินยอม → ตั้งชื่อเครื่อง เลขครุภัณฑ์ ปีงบ ราคา → ติดตั้ง
  3. เครื่องขึ้นในกลุ่ม "เครื่องใหม่" บนแดชบอร์ด แล้วค่อยย้ายไปกลุ่มแผนก (แนวคิด: ชุดติดตั้งเดียวใช้ได้ทุกเครื่อง ดู client-setup/README.md)
  4. ถ้าเครื่องไม่ขึ้น: รัน Check-Network.cmd บนเครื่องนั้น บอกว่าเครื่องอยู่วงไหน ต่อเซิร์ฟเวอร์ได้ไหม

แบบ ข: จากหน้าแดชบอร์ด (ง่ายที่สุด)

  1. กดเมนู ดูแลเครื่อง ▾ → เพิ่มเครื่อง (ติดตั้งเอเจนต์) · ถ้ายังไม่มีเครื่องเลย หน้าแดชบอร์ดจะมีปุ่ม ➕ เพิ่มเครื่องแรก หรือกด รีเฟรช หน้าติดตั้งจะเด้งขึ้นมาเอง
  2. ถ้ายังไม่มีกลุ่มอุปกรณ์ ระบบสร้างกลุ่ม เครื่องใหม่ ให้ ถ้ามีหลายกลุ่ม เลือกกลุ่มที่จะให้เครื่องขึ้น
  3. หน้าต่าง เพิ่ม SCP-Remote Agent: เลือกระบบปฏิบัติการ (Windows / Linux / macOS / มือถือ) แล้วดาวน์โหลดตัวติดตั้ง
  4. เอาไฟล์ไปรันที่เครื่องลูก (สิทธิ์ผู้ดูแล) กด Install รอไม่กี่วินาที เครื่องจะขึ้นบนแดชบอร์ด

แบบ ค: ระบบอื่นนอกจาก Windows

โฟลเดอร์ server/agents/ มีเอเจนต์สำเร็จรูปของ MeshCentral สำหรับ Windows (x86/x64/ARM64), Linux (x86, ARM, MIPS ฯลฯ), macOS, FreeBSD และ Android ดาวน์โหลดผ่านหน้าเพิ่มเอเจนต์ได้เหมือนกัน

ติดตั้งแล้วขึ้น "Could not find a part of the path ... MeshAgent.tag" แปลว่ามีบริการ Mesh Agent ค้างอยู่แต่ไม่มีไฟล์ ให้รัน Command Prompt แบบผู้ดูแล: sc stop "Mesh Agent" แล้ว sc delete "Mesh Agent" แล้วติดตั้งใหม่

โปรแกรมฝั่งช่าง

  • SCP-Remote Desktop (hospital/desktop-app): โปรแกรมบนเครื่องช่าง เปิดผังห้อง ลากไฟล์ส่งไปเครื่องลูก ดู DESKTOP-APP.md
  • หน้ามือถือ https://<เซิร์ฟเวอร์>:8443/m: ดูสถานะ กดแก้ปริ้นไม่ออกได้จากมือถือ

5. การใช้งานทุกเมนู

แดชบอร์ด

ตัวเลขสรุป (ทั้งหมด/เปิดอยู่/กำลังใช้/ว่าง/ปิด/ต้องดูแล) ช่องค้นหาชื่อ ผู้ใช้ หรือ IP ตัวกรองตามแผนก และ 3 เมนูหลักด้านบน:

เมนูมีอะไร
ดูแลเครื่อง ▾งานช่างค้างทั้ง รพ. · ตรวจสุขภาพทุกเครื่อง · สุขภาพดิสก์ทั้ง รพ. · เครื่องพิมพ์ทั้ง รพ. · ติดตั้งฟอนต์ไทย · แจ้งซ่อม/ตรวจระบบ · คลังไดรเวอร์
รายงาน ▾สรุปประจำวัน · รายงานและชาร์ต (พิมพ์) · ออกรายงานการใช้งาน · ออกรายการครุภัณฑ์ · QR ติดเครื่อง
งบและประเมิน ▾คลังราคากลาง/ประมาณการซ่อม · เกณฑ์ประเมิน · ตรวจเครื่อง (ชนิด/Windows แท้)

ผัง รพ. 2.5 มิติ

เมนูซ้าย "ผังแผนที่ รพ." แสดงทุกตึกพร้อมจำนวนเครื่องเปิด/ทั้งหมดและเครื่องเสี่ยง โหมด สถานะ / ความเสี่ยง / แผนเปลี่ยนเครื่อง ซูม หมุน ลากได้ คลิกตึกเพื่อดูภายใน คลิกเครื่องเพื่อเปิดรายละเอียด "จัดตำแหน่งเครื่อง" ใช้วางเครื่องลงห้อง

หน้ารายละเอียดเครื่อง

  • รีโมตหน้าจอ (ขออนุญาตผู้ใช้ก่อนเข้าคุม), เทอร์มินัล, ไฟล์, ส่งข้อความ, เปิด/ปิด/รีสตาร์ต
  • เครื่องนี้ต้องทำอะไร (ใบงานช่าง): งานเรียง 🔴 ด่วน 🟡 ควรทำเร็ว 🔵 วางแผน แต่ละงานมีปุ่มแก้ (ถ้าทำจากที่นี่ได้) หรือป้าย 🚶 ไปหน้าเครื่อง และ วิธีซ่อม (สาเหตุ หลักการ ขั้นตอน ตรวจผล ข้อควรระวัง) ปุ่ม 🖨️ พิมพ์ใบงานพร้อมช่องลงชื่อ
  • ผลตรวจละเอียดทั้งหมด: ระบบ ฮาร์ดแวร์ (แรม CPU ดิสก์ทุกลูกพร้อม % สุขภาพ) เครือข่าย เครื่องพิมพ์ ความเร็ว การติดตั้ง Windows ฟอนต์ และกราฟแนวโน้มจากการตรวจเช้า

การตรวจใช้เวลาราว 15 วินาที อ่านอย่างเดียว ปุ่มแก้ที่มี: แก้ปริ้นไม่ออก (ล้างงานค้าง + รีสตาร์ต Spooler), รีสตาร์ต Spooler, พิมพ์ทดสอบ, ให้เครื่องพิมพ์ทำงานต่อ, ล้าง DNS, เปิดบริการ (เฉพาะรายการที่กำหนด), TRIM SSD, โหมดพลังงาน Balanced, ตั้งชื่อ PACS (hosts), เปิด/ปิดโปรแกรมเปิดพร้อมเครื่อง, ติดตั้งฟอนต์ไทย (ตรวจ SHA-256 ก่อนลง), ล้างไฟล์ชั่วคราว

สุขภาพดิสก์ (%)

อ่าน SMART ของดิสก์ทุกลูก: SSD เริ่มจากอายุที่เหลือที่ดิสก์บอก HDD หักตามชั่วโมงใช้งานเกิน 30,000 ชม. แล้วหักตาม bad sector (ย้ายแล้ว / รอย้าย / อ่านไม่ได้) และการอ่านพลาด ถ้า Windows/SMART เตือนใกล้เสีย ไม่เกิน 10% · ต่ำกว่า 40% = ควรเปลี่ยน · ต่ำกว่า 80% หรือมี bad sector = ควรดู (สูตรเต็มใน HEALTH-CHECK.md)

ตรวจเช้าอัตโนมัติ 07:30

เซิร์ฟเวอร์ตรวจทุกเครื่องที่เปิดอยู่เองทุกเช้า เก็บผลและแนวโน้ม สรุปเรียงเครื่องค้าง/ช้าก่อน ตามด้วยดิสก์ที่ควรเปลี่ยน ส่งสรุปเข้า Telegram หรือ webhook ได้โดยตั้งใน .local/scp-remote/config.json ส่วน settings:

"scpmorningcheck": "07:30",                          // หรือ "off"
"scptelegram": { "token": "<bot token>", "chat": "<chat id>" },
"scpalertwebhook": "https://..."                      // ถ้ามีระบบรับ JSON

แก้แล้วต้องรีสตาร์ตบริการ

งานไอทีอื่น ๆ

  • แจ้งซ่อม / ตรวจระบบ: บันทึกงานซ่อม ประวัติเครื่อง (IT-OPERATIONS.md)
  • คลังไดรเวอร์: อัปโหลดไดรเวอร์ของ รพ. แล้วสั่งลงที่เครื่องลูก (เริ่มต้นว่าง)
  • QR ติดเครื่อง: พิมพ์สติกเกอร์ สแกนแล้วเปิดหน้าเครื่องนั้น
  • แผนงบประมาณ 5 ปี / เกณฑ์ประเมิน: ประเมินอายุเครื่อง CPU แรม Windows 11 และวางแผนเปลี่ยนตามปีงบ (เริ่ม ต.ค.)

6. กระบวนการทำงานประจำ

6.1 รับเครื่องใหม่เข้าระบบ

ลง Windows + โปรแกรม รพ.→เพิ่มเครื่อง (ดูแลเครื่อง ▾) หรือ SCP-Remote-Setup.exe→ย้ายเข้ากลุ่มแผนก→ตรวจสุขภาพ + ลงฟอนต์ไทย→วางตำแหน่งบนผัง

6.2 ทุกเช้า (10 นาที)

  1. เปิด สรุปประจำวัน หรืออ่านสรุปใน Telegram
  2. เปิด งานช่างค้างทั้ง รพ. → แท็บ 🔴 ด่วน
  3. กดแก้งานที่ "ทำจากที่นี่ได้" ก่อน (เช่น งานพิมพ์ค้าง)
  4. งาน 🚶 ไปหน้าเครื่อง: กดพิมพ์ใบงาน แล้วออกไปทำตามรอบ

6.3 ซ่อมเครื่องหนึ่งเครื่อง

เปิดเครื่องนั้น→ดู "เครื่องนี้ต้องทำอะไร"→อ่านวิธีซ่อม→กดแก้ หรือไปหน้าเครื่อง→กดตรวจอีกครั้ง ยืนยันผล→บันทึกในแจ้งซ่อม

ทุกปุ่มแก้ถูกบันทึกในประวัติเครื่องโดยอัตโนมัติ (ใคร กดอะไร ผลเป็นยังไง)

6.4 ดิสก์ใกล้เสีย

  1. สุขภาพดิสก์ทั้ง รพ. → แท็บ "ควรดู/ควรเปลี่ยน"
  2. ต่ำกว่า 40% หรือมี bad sector "อ่านไม่ได้": แจ้งผู้ใช้ สำรองข้อมูลวันนั้น
  3. เปลี่ยนเป็น SSD (โคลนถ้าลูกเดิมยังอ่านได้ ไม่งั้นลง Windows ใหม่)
  4. ห้ามรัน CHKDSK /R หรือ Defrag กับดิสก์ใกล้เสียก่อนสำรองข้อมูล

6.5 ปริ้นไม่ออก

  1. เปิดเครื่องนั้น (หรือ /m บนมือถือ) → แก้ปริ้นไม่ออก
  2. ยังไม่ได้: ดูสถานะเครื่องพิมพ์ (Offline / กระดาษติด / หมึก) → ไปหน้าเครื่อง
  3. อย่ากดแก้ปริ้นกับเครื่องที่เป็นเซิร์ฟเวอร์ SCPPrint เครื่องอื่นพิมพ์ผ่านเครื่องนั้น

6.6 วางแผนงบประจำปี

  1. งานช่างค้างทั้ง รพ. → 🖨️ พิมพ์สรุปงาน + รายการอะไหล่ (มีราคาประมาณและช่องผู้อนุมัติ)
  2. แท็บแผนงบประมาณ 5 ปี → พิมพ์รายงานแผนงบ (PDF)
  3. เทียบราคากับคลังราคากลาง

7. SCPclear และ SCPPrint

สองโปรแกรมนี้ใช้ที่หน้าเครื่อง ส่วนแดชบอร์ด SCP-Remote ใช้จากระยะไกล การตรวจสุขภาพและปุ่มแก้บนแดชบอร์ดคือการนำส่วนตรวจของ SCPclear มาทำงานผ่านเอเจนต์ และแดชบอร์ดยังตรวจได้ว่าเครื่องไหนลง SCPPrint และเปิดอยู่ไหม

7.1 SCPclear: ทำความสะอาดและปรับแต่งเครื่อง

เปิดโปรแกรม

  1. ดับเบิลคลิก RUN.bat ในโฟลเดอร์ tools/SCPclear-plus (หรือทางลัด SCPclear บนเดสก์ท็อปหลังรัน START-HERE)
  2. กด Yes เมื่อ Windows ขอสิทธิ์ผู้ดูแล โปรแกรมจะเปิดในหน้าต่างที่สอง
  3. ถ้ามีตัวหนังสือสีแดงในหน้าต่างดำ ให้ถ่ายรูปเก็บไว้ดูสาเหตุ

SCPclear.exe เป็นรุ่นเก่า ถ้าต้องการ exe รุ่นล่าสุดให้รัน BUILD-EXE.bat แล้วใช้ตัวใหม่

หน้าจอหลัก: เลือกสิ่งที่จะทำ แล้วกด "เริ่มทำงาน"

ขั้นตอนแนะนำสำหรับเครื่องที่ช้า

  1. เปิด SCPclear → ตรวจสอบเครื่อง → ปรับตามคำแนะนำ
  2. เช็กว่าติ๊ก Restore Point และ ยืนยันก่อนทำ แล้ว
  3. กด เริ่มทำงาน รอจนขึ้นสรุปผล แล้วกดรีสตาร์ท
  4. หลังรีสตาร์ท เปิดแดชบอร์ด SCP-Remote กดตรวจเครื่องนั้นอีกครั้ง ดูว่างาน "แก้เครื่องค้าง/ช้า" หายไหม

  • ถอน OneDrive / ลบ Bloatware ย้อนกลับยาก ตรวจก่อนว่าผู้ใช้ไม่ได้ใช้

7.2 SCPPrint: แชร์เครื่องพิมพ์ให้เครื่องอื่นพิมพ์ผ่าน

ทำให้คอมเครื่องหนึ่งเป็น print server พอร์ต 9100 เหมือนกล่อง print server ฮาร์ดแวร์ เครื่องอื่นในวง LAN ส่งงานพิมพ์มาที่เครื่องนี้ แล้วเครื่องนี้ส่งต่อไปเครื่องพิมพ์ เหมาะกับเครื่องพิมพ์ USB ที่ต่ออยู่กับคอมเครื่องเดียวแต่หลายเครื่องต้องใช้ หรือเครื่องพิมพ์สติกเกอร์/ฉลาก (เช่น Zebra ZD230)

ติดตั้ง

  1. เลือกคอมที่ต่อเครื่องพิมพ์อยู่และเปิดตลอดเวลา (เป็น "เครื่องแม่")
  2. รัน tools/SCPPrint/bin/SCPPrint_Setup.exe (หรือทางลัด "ติดตั้ง SCPPrint" บนเดสก์ท็อป)
  3. เปิดโปรแกรม SCPPrint จะเห็น IP เครื่องนี้ อยู่บนสุด จด IP นี้ไว้ (ควรตั้ง IP คงที่)

เพิ่มเครื่องพิมพ์ (แท็บ "หลัก")

  1. ช่อง เพิ่มปริ้นเตอร์ใหม่ เลือกชนิด:
    • USB (ปริ้นเตอร์ในเครื่องนี้): เลือกเครื่องพิมพ์จากรายการ (กด รีเฟรช ถ้าไม่เห็น) งานจะส่งผ่านคิว Windows
    • เครือข่าย (มี IP ตัวเอง): ใส่ IP และพอร์ตของเครื่องพิมพ์ กด ทดสอบการเชื่อมต่อ
  2. ตั้ง พอร์ตรับงาน: เครื่องพิมพ์แรกใช้ 9100 ตัวถัดไป 9101, 9102 …
  3. ใส่ ชื่อไดรเวอร์ (ไม่บังคับ) ถ้าใส่ สคริปต์ติดตั้งเครื่องลูกจะเพิ่มเครื่องพิมพ์ให้ครบในขั้นเดียว
  4. กด + เพิ่มปริ้นเตอร์ โปรแกรมจะเปิดไฟร์วอลล์ ใส่ข้อยกเว้น Windows Defender และอัปเดตสคริปต์ติดตั้งเครื่องลูกให้เอง
  5. กด ▶ เริ่มทำงานทั้งหมด สถานะต้องขึ้นว่ากำลังทำงาน

แท็บ "จัดการ / อัปเดต"

  • ตาราง พอร์ตรับงาน → ปลายทาง → จำนวนงานพิมพ์ ของแต่ละพอร์ต · ปุ่ม แก้ไข / ลบ
  • ตัวเลือก เปิดโปรแกรมนี้พร้อม Windows (ควรเปิดไว้) และเปิดแบบย่อลงถาดระบบ
  • บันทึกการทำงาน (Log) แยกรายวัน เก็บ 15 วัน · ปุ่ม เปิดโฟลเดอร์ ดูไฟล์ตั้งค่าและ log (%LOCALAPPDATA%\SCPPrint)
  • สร้างสคริปต์ติดตั้งเครื่องลูก (.ps1) เพื่อบันทึกไปไว้ที่อื่น เช่น แฟลชไดรฟ์

ตั้งค่าเครื่องลูก (เครื่องที่จะพิมพ์ผ่าน)

  1. ก๊อปไฟล์ install-client-printer.ps1 ที่ SCPPrint สร้างไว้ไปที่เครื่องลูก
  2. ลงไดรเวอร์ของเครื่องพิมพ์รุ่นนั้นที่เครื่องลูกก่อน (ไดรเวอร์เดียวกับเครื่องแม่)
  3. คลิกขวาไฟล์ → Run with PowerShell (แบบผู้ดูแล) สคริปต์จะสร้างพอร์ต SCPPrint_9100 ชี้ไปที่ IP เครื่องแม่
  4. ถ้าในสคริปต์มีบรรทัด # Add-Printer ... <ใส่ชื่อไดรเวอร์ตรงนี้> ให้รัน Get-PrinterDriver ดูชื่อไดรเวอร์ แล้วใส่ชื่อแทนและเอา # ออก แล้วรันใหม่
  5. หรือตั้งเอง: Control Panel → Devices and Printers → Add a printer → Add a local printer → Create a new port: Standard TCP/IP Port → ใส่ IP เครื่องแม่ → พอร์ต 9100 (หรือ 9101 …) → เลือกไดรเวอร์
  6. สั่งพิมพ์หน้าทดสอบ ตัวเลข "งานพิมพ์" ในตารางของ SCPPrint ต้องเพิ่มขึ้น
ข้อควรระวัง
  • เครื่องแม่ต้องเปิดตลอดเวลา ถ้าปิดเครื่องหรือปิดโปรแกรม เครื่องลูกทั้งหมดจะพิมพ์ไม่ได้ (กด X = ย่อลงถาด ไม่ได้ปิด)
  • อย่ากด "แก้ปริ้นไม่ออก" หรือล้างคิวที่เครื่องแม่ จะล้างงานของเครื่องอื่นที่ส่งมาด้วย
  • SCPPrint รับงานเฉพาะวง LAN และจำกัดขนาดงาน 200 MB ต่องาน (โหมดคิว Windows)
  • บนแดชบอร์ด ถ้าเครื่องไหนลง SCPPrint แต่ไม่ได้เปิด จะขึ้นเป็นงาน 🔴 ด่วน "เปิด SCPPrint"

แก้โค้ด SCPPrint

ไฟล์หลัก print_server_full.py (Python 3.12, pip install pywin32 pystray pillow) · สร้าง exe ด้วย build.bat (PyInstaller ตาม SCPPrint.spec) · สร้างตัวติดตั้งด้วย Inno Setup จาก installer.iss

8. สำหรับคนที่จะแก้ไข/พัฒนาต่อ

โครงสร้างไฟล์ที่ รพ. เพิ่ม

ที่อยู่คืออะไร
hospital/*.jsโมดูลฝั่งเซิร์ฟเวอร์: operations.js (งานไอที, เก็บผลตรวจ, ประวัติ) morning-check.js mobile.js driver-library.js templates.js
public/scripts/scp-*.jsฝั่งเบราว์เซอร์: scp-dashboard.js (แดชบอร์ด) scp-health.js (ตรวจสุขภาพ ดิสก์ ใบงาน วิธีซ่อม) scp-map*.js (ผัง) scp-mobile.js scp-operations.js scp-programs.js ฯลฯ
public/styles/scp-*.cssธีมสีชมพูของ รพ.
views/*.handlebarsเทมเพลตหน้าเว็บ (แก้แล้วต้อง npm run build:hospital)
hospital/tests/เทสต์ทั้งหมด รันด้วย npm run test:hospital
hospital/UPSTREAM-CHANGES.mdรายการไฟล์ของ MeshCentral ที่ถูกแก้ (อ่านก่อนอัปเกรด MeshCentral)

แก้อะไรแล้วต้องทำอะไรต่อ

แก้ไฟล์ต้องทำ
public/ (JS, CSS)ไม่ต้องรีสตาร์ต แต่ต้องเปลี่ยนเลขเวอร์ชัน ?v=... ในแท็ก script/link ของ views/default.handlebars แล้ว build ไม่งั้นเบราว์เซอร์ใช้ไฟล์เก่าจากแคช
views/*.handlebarsnpm run build:hospital (ไม่ต้องรีสตาร์ต)
hospital/*.js, meshcentral.js, meshagent.jsรีสตาร์ตบริการ (ผู้ใช้ทุกคนจะหลุดล็อกอิน แจ้งก่อน)

ข้อควรรู้ที่เคยพลาดมาแล้ว

  • สคริปต์ที่ส่งให้เอเจนต์รัน ต้องเขียน 1 คำสั่งต่อบรรทัด เอเจนต์ป้อน PowerShell ทีละบรรทัด และควรแปลงอักษรไทยเป็น \uXXXX ก่อนส่งกลับ (ไม่งั้นเพี้ยนตาม code page)
  • เอเจนต์รันได้ทีละคำสั่ง ส่งซ้อนจะได้ COMMAND_BUSY ใน scp-health.js มีคิวต่อเครื่องให้แล้ว
  • ScpOperations.request(op, data) ห้ามมีฟิลด์ชื่อ action ใน data จะไปทับชื่อช่องทาง scpops
  • ไฟล์ในโปรเจกต์ใช้บรรทัดแบบ LF ถ้าแก้ด้วยโปรแกรมที่เขียน CRLF ไฟล์จะเปลี่ยนทั้งไฟล์
  • เพิ่มปุ่มแก้ใหม่: เพิ่มฟังก์ชันใน FIX ของ scp-health.js (ต้องพิมพ์ SCP_FIX:{json}) + ชื่อใน ACTIONS ของ operations.js + เทสต์
  • เพิ่มวิธีซ่อม: เพิ่มใน GUIDE และ KINDS ของ scp-health.js มีเทสต์ตรวจว่าทุกงานมีวิธีซ่อม
  • แก้ไฟล์ของ MeshCentral ต้องใส่คอมเมนต์ SCP-Remote: และจดใน UPSTREAM-CHANGES.md

10. แนวทางพัฒนาต่อไป

เป้าหมาย: ให้ระบบเป็น "งานช่าง" ที่รู้ว่าเครื่องไหนต้องแก้อะไร ขาดอะไร ก่อนผู้ใช้จะแจ้ง

ขั้นทำอะไรสถานะ
1. ใบงานช่างรายเครื่อง + วิธีซ่อมสรุปงานต่อเครื่อง เรียงความด่วน มีวิธีซ่อม 24 แบบ✅ เสร็จ
2. งานค้างทั้ง รพ. + อะไหล่รวมงานทุกเครื่อง พิมพ์ใบขอซื้อ✅ เสร็จ
3. มาตรฐานเครื่อง รพ.กำหนดโปรแกรม/การตั้งค่าที่ทุกเครื่องและแต่ละแผนกต้องมี แล้วเทียบว่าเครื่องไหนขาดอะไรรอรายการโปรแกรมของหน่วยงาน
4. ปุ่มลงโปรแกรมที่ขาดคลังตัวติดตั้งที่ตรวจ SHA-256 ลงแบบเงียบ ทีละเครื่องหรือทั้งแผนก ("ชุดเครื่องใหม่")ออกแบบแล้ว
5. ประวัติและอาการซ้ำบอกเครื่องที่เสียเรื่องเดิมบ่อย ใช้ตัดสินใจเปลี่ยนเครื่องข้อมูลมีแล้ว
แจ้งเตือน Telegramส่งสรุปตรวจเช้าเข้ากลุ่ม Telegram ของทีม (ระบบรองรับแล้ว ใส่ token ใน config) และต่อ LINE ผ่าน webhook ในอนาคตรอ bot token
ลง Windows จากระยะไกลสั่งลง Windows ใหม่ผ่านเอเจนต์ แล้วเอเจนต์ต่อกลับเอง (ทดลองสำเร็จแล้ว ต้องปรับให้ไฟล์ตอบคำถามติดตั้งไปถึงเครื่องผ่าน $OEM$)ทดลองแล้ว ยังไม่รวมในชุดนี้
ตัวติดตั้งเครื่องลูกถ้าเจอบริการ Mesh Agent ค้างโดยไม่มีไฟล์ ให้ติดตั้งใหม่เองแทนการแจ้ง errorรอแก้
ไอคอนทั้งระบบเปลี่ยนอีโมจิที่เหลือเป็นไอคอนเส้นแบบเดียวกับเมนูทำแล้วบางส่วน
ข้อเสนอแนะ: ก่อนเพิ่มฟีเจอร์ใหม่ เขียนเทสต์ก่อน รัน npm run test:hospital ให้ผ่านทุกข้อ แล้วค่อยรีสตาร์ตบริการ และแจ้งผู้ใช้ทุกครั้งก่อนรีสตาร์ต
